== What this proves
The PAX RaBitQ→SQ8 cold-scan cascade (stage-1 binary rank → stage-2 SQ8 rerank,
no f32 GET) holds `recall@10 ≥ 0.93` at both N=1k and N=100k *on this corpus*. This
is the recall **floor** the storage-format mandate (#8) requires; the qa-gate
`pax-recall-ratchet` job enforces it on every develop→qa promotion; the ratchet only
goes up (#10).

[NOTE]
====
**Representativeness caveat (audit 2026-06-25, `docs/history/planning/PAX_SUBSTRATE_DESIGN_PLAN_2026_06_25.adoc`).**
This corpus is **DIM=64 seeded-LCG synthetic**, N≤100k, with a **fixed absolute** REFINE=1000
(=1% of corpus only at N=100k; <0.1% at N=1M). RaBitQ recall is dimension- and
distribution-dependent, so this is a **fast CI floor**, *not* a guarantee for production
high-dim embeddings (768/1536-d) or N≥1M. The **default-on flip (TD-150) is gated** on an
additional real-embedding (e.g. SIFT1M / 768-d ada/E5) **N≥1M** recall artifact — this
synthetic ratchet alone is not sufficient evidence for the flip.
====

remain the levers if recall regresses.
