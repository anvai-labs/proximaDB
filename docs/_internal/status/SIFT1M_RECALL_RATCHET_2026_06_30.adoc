= SIFT1M PAX RaBitQ→SQ8 Recall Ratchet — WS8 Real-Dataset Run 2026-06-30

[IMPORTANT]
====
**LAYOUT CAVEAT (added 2026-10-09, TD-SIFTCOMPACT-1).** The figures below describe
an **L0-only, uncompacted** layout, not a compacted one. At N >= 100 000 the
harness crossed the L0 compaction threshold and compaction *was* attempted, but it
failed the catalog-object-id admission check; the error was recorded on the flush
result and logged at `warn!`, so the arms measured a pre-compaction layout with
nothing to signal it. That is now the **stated** intent -- the shared collection
helper pins `compaction:off`, making the layout deterministic rather than
accidental -- but it means the recall here is not evidence about the compacted
product.

`BENCHMARK_EVIDENCE.toml`'s `pax_rabitq_sq8_sift1m_recall_at_10` entry carries the
same caveat; this document is the other half of that pair, and TD-SIFTCOMPACT-1
names both as needing re-baselining against a compacted layout. See also
TD-IVF2ENGAGE-1, whose own headline finding was retracted once a
compaction-quiescence barrier was added to the sibling IVF2 test.
====

== What this proves
On **real** SIFT image descriptors (not synthetic LCG), the PAX RaBitQ→SQ8 cascade holds
**recall@10 = 0.9905 at N=100k** — well above the 0.90 floor and *higher* than the
synthetic-DIM=64 ratchet's 0.932. This directly refutes the representativeness caveat's
specific worry that real (mildly clustered) data degrades RaBitQ recall: at N=100k it does
not. The cascade is sound on real 128-d Euclidean data.
