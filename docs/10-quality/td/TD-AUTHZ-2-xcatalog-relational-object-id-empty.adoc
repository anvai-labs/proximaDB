== History

Symptom: `xcatalog.tables.object_id` was blank for SQL-DDL tables, so `abac_relational_transport_e2e`
failed with `ParseIntError { kind: Empty }`. The suite had **never run in CI** (`#![cfg(feature =
"abac-policy")]` + no lane passing the feature ⇒ zero tests, exit 0); #1544 wired the lane and it
failed immediately. Root cause: the server registers the WAL-backed **`SystemCatalog`**, not
`NativeCatalog`, and `SystemCatalog::create_table` minted no ids; the relational ABAC gate
(`stable_namespace_id` AND `object_id`) could therefore never admit — relational ABAC was
*structurally inert* (fail-closed). Vector collections were unaffected because the collection manager
pre-sets `object_id` from `collection.id`.

Two distinct fixes, both required — proven because the e2e failure **moved** (`:285` parse →
`:786/:904/:1023` hot-visibility) between them. Object-id floor is *derived* from recovered state
(`max_object_id() + 1`, adopt-don't-overwrite via `fetch_max`), so no extra fsync or second recovery
path; `object_ids_are_never_reissued_across_a_restart` pins that a new table can never inherit a dead
table's grants. The typed-identity half was a **re-land of #1406's machinery reverted in #1425** for
collapsing cross-tier ANN recall; it was re-landed as its own recall-gated PR (TD-RECALL-2) after the
collapse no longer reproduced — root cause never identified, so the recall e2e stays its gate.

Lessons that still apply:

* **Establish which implementation actually serves the path before testing one** — `NativeCatalog`
  was exonerated correctly and irrelevantly (#1559).
* `unwrap_or_default()` on an identity turns "no identity" into a value indistinguishable from an
  empty column.
* A zero is evidence about the search: `running 0 tests … 0 filtered out` means the feature gate
  compiled nothing; and a positive control must exercise the *same filter path* as the negative
  result (a `grep -v` comment filter once ate the only `PROXIMADB_TYPED_PATHS` code site).
* Teeth proof: revert only the implementation, never `git stash` (it removes the tests too).

Evidence: `abac_relational_transport_e2e` — 3 passed on the re-land, 3 FAILED with only
`system_catalog{,_state}.rs` reverted.
