== History

*Finding:* `FlushCoordinator::post_flush_operations` carried a "Compaction would be triggered here" stub — `compaction_triggered=true` fed tiering accounting but never scheduled the compactor, so the armed `AppendBulk` default was not real end-to-end. #1012 wired the trigger to tokio-native background execution (no non-daemon threads; a synchronous test hook keeps it deterministic) honoring `OrchestratorCompactionConfig::effective_for_collection_tags` and the WLP-2/4 cascade. *Lesson:* an "armed" default is only real when a test proves the trigger reaches execution in production code.
Swap atomicity is carried by ADR-062 D6 (Iceberg-style fresh name + manifest advance). Gating: armed by default for `AppendBulk`, `compaction:off` opt-out, falsy `PROXIMADB_L0_COMPACTION_ENABLED` = master kill-switch.
