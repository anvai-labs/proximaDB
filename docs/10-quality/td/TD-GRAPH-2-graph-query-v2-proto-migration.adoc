== History (shipped)

* **Value-loss fix (#651).** The REST Cypher handler ran on the v1 proto and discarded every column
  value (`row.columns.keys().map(|k| (k, Value::Null))`) — `/api/v2` URL, v1 wire types. New
  `GraphPort::execute_query_json` returns `QueryFacadeAdapter::graph_query`'s raw JSON rows directly (no
  v1 `QueryValue` round-trip); the v1 `QueryValue`/`PropertyValue` JSON helpers were deleted. Lesson: both
  proto stacks called the same adapter that already yielded `Vec<serde_json::Value>`, so for a JSON
  surface either proto wrapper was a needless round-trip.
* **Module relocation (#1598).** The served router now lives in `rest/canonical/graph.rs`; the
  unmounted duplicate graph router (and `src/network/rest/v1/`) is deleted.

== Remaining (full v1 retirement)

* Retire `GraphPort::execute_query` (the v1 `GraphQueryResponse` method — still present,
  `graph_port.rs`) once no caller needs it, and drop the v1 `graph.proto` query types + the
  `property_value_to_v1`/`_to_v2` converters (`src/network/grpc/v2/graph_service.rs`, still present
  2026-10-15).
* Plumb `parameters` binding through the Cypher REST request (currently ignored), and
  implement the `/rag` stub (`/graphs/{graph_id}/rag` still routes to `not_implemented_handler`).
