== Premise (verified 2026-10-16)

* No file under `src/network`, `src/services`, `src/query`, `apps` or `crates/platform` uses
  `crate::transaction::`, `storage::transaction::`, `multimodel::transaction` or
  `MultiModelTransactionManager`.
* Two **different** structs are named `CrossModelTransactionCoordinator`
  (`src/transaction/coordinator.rs:111` and `src/services/transaction/`). The second is referenced
  from `services/dml/mod.rs` only in a doc comment.
* Only their own unit tests and `tests/transaction_integration_test.rs` /
  `tests/cross_model_transaction_e2e.rs` construct them.

== Plan

. Re-verify the premise at start (filing rule 7). Check `tests/cross_model_transaction_e2e.rs`
  for a live caller that grep missed.
. Move anything ADR-095 reuses (for example the isolation-level enum) into `proximadb-txn-core`.
. ADR-071 cites `MultiModelTransactionManager` as the future cross-modal path. Amend ADR-071 to
  point at ADR-095's `TxnCommit` record instead: cross-modal atomicity on one node is one commit
  record spanning modalities, not 2PC.
. Delete the three subsystems and their tests in one PR, recording the line count removed.
