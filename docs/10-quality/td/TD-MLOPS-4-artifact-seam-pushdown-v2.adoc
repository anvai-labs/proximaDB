== History

* **Origin.** The TD-MLOPS-2 opening (#1876) shipped an `ArtifactRepository` port + `RunQuery` pushdown
  with an unsafe implementation: distinct tenant ids could share artifact bytes through lossy directory
  mapping, and blocking filesystem work ran inside async request paths. #1891 reverted both and hardened
  the concrete store (injective `mlflow_artifacts_v2/<byte-length>/<hex>` tenant roots, capability-relative
  no-follow traversal, `spawn_blocking`, Windows fail-closed).
* **Design rule that still applies — extract the port FROM the proven implementation**, not the reverse.
  The port encodes the lessons as contract: (1) tenant bound at construction (factory), never a path
  argument; (2) async-only, implementations own their blocking strategy; (3) platform capability declared
  before any I/O; (4) segments validated IN the port via an `ArtifactPath` newtype; (5) the red evidence
  (tenant collision, symlink/parent-swap) becomes the capability-shaped conformance battery, run against
  in-memory, hardened local and S3.
* **Pushdown.** `search_runs(&RunQuery)` (clauses over params/tags/metrics with absent-value semantics;
  default composes `list_runs`, substrates override) re-landed together with its consumers so one review
  covered the seam and its users, not an orphan abstraction.
* **S3 backend.** Selected by `PROXIMADB_MLFLOW_ARTIFACTS_URL` (unset = hardened local), feature-gated
  behind `aws` with a fail-closed stub; GET-miss falls back to a prefix listing because object stores have
  no directories. The battery's first run against real MinIO caught a bug (child slicing used the
  caller-relative prefix against absolute `ObjectMeta` locations).
