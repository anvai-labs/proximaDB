== History

The ~260-line pgwire dispatch block re-decided inside a God-`if` (native primary, DuckDB primary, DataFusion
floor, "last-write-wins" route re-stamp, native shadow, a separate PAX branch), so the decision was not
authoritative, the cost model learned the last-stamped route rather than the decided one, and adding an engine
meant editing the block. Now `route_select_advised` folds the env master switches, ADR-058 primary eligibility
(`RouteFlags` + `parquet_primary_eligibility`) and the cost-model override into `decision.backend`;
`flip_eligible` refuses to flip onto an ineligible primary; each primary owns its fall-through to the shared
DataFusion floor.

Design decision that still applies (ADR-059): `ComputeBackend` stays a **closed enum** — a separation-of-concerns
refactor, not an open plugin registry. No route changed.

Evidence: decision unit tests in `compute_scheduler.rs` (e.g. `join_bearing_with_native_flag_stays_datafusion_native_ineligible`,
`native_and_duckdb_primary_eligibility_are_disjoint`); `tests/native_route_pgwire_e2e.rs`
`native_decline_attributes_to_datafusion_floor_not_the_declined_primary`; TPC-H/TPC-DS ratchets unchanged.
