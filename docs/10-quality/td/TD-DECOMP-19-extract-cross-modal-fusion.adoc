== History (shipped)

`cross_modal_fusion.rs` (the modality-agnostic `Fuser` that calibrates + fuses + ranks `(oid, score)`
lists) moved verbatim; it is `std`-only with all 9 of its types in-file. 8 callers resolve through the
root shim.

* Decision: extract the live core, not `hybrid/fusion.rs` (the original target) — that file's
  `FusionStrategy` carries `#[deprecated]` variants pointing *to* `cross_modal_fusion::Fuser`, so the
  migration direction is away from it.

== Open follow-ups

* The deprecated `hybrid/fusion.rs` (32 tests) remains a future extraction or a delete candidate once
  the migration to `cross_modal_fusion::Fuser` completes. (Verified 2026-10-15: still root-side, still
  `#[deprecated]`/`#[allow(deprecated)]`.)
* From link:TD-DECOMP-14-extract-core-resilience.adoc[TD-DECOMP-14]'s follow-up list: `search/hybrid` (44 tests) — `src/core/search/hybrid/`
  (`builder`, `coordinator`, `fusion`, `reranker`) is still root-side.
