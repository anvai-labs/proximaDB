== History

`manifest_url` called the collection-scoped `manifests_subprefix()` on a tenant-system path, rendering
`data/<tenant>///manifests/warm_cache.json`; Azure rejected it (`Invalid path: not an azure path`)
while a local filesystem collapsed the triple slash, so unit/bench coverage passed. Both directions
were best-effort (`warn!` / `(0, 0)`), which is why it was silent. **Class fix, not point fix:** one
struct carried two meanings whose valid methods depended on which constructor ran — now the misuse does
not compile. Do not "make `manifests_subprefix()` valid on a tenant-system path" (that would fabricate
a namespace segment).

Mis-attributions retired: this error was **not** the cause of the adjacent SIFT-1M ingest stall
(TD-FLUSH-6), and is **not** evidence of an unpopulated `namespace_id` — `DrPathBuilder` fails closed
on an empty namespace (`MissingNamespaceId`), so a missing namespace yields an error, never a
malformed path.
