[cols="1,3", options="header"]
|===
| Field | Value
| Status | **Done (2026-10-07).** `EncryptedFilesystem::list` now reports logical names, stripping `encrypted_extension` from file entries' `name`/`url`/`metadata.path` (#1954, `fc6fefe32`).
| Priority | HIGH when filesystem encryption is configured (a supported deployment: `FilesystemFactory::maybe_wrap_with_encryption`).
| Component | `crates/storage/proximadb-storage-encryption/src/filesystem.rs`
| Relates to | link:TD-USUB-1-durable-relational-record-store-and-wal-rotation.adoc[TD-USUB-1] (segment discovery), link:TD-SSTCLEAN-1-drop-collection-cleanup-lists-the-filesystem-root.adoc[TD-SSTCLEAN-1] (a defect this one was masking), mandate #1

== History

* Defect: `actual_path` appended `.enc` on every read/write/delete/exists, but `list` passed through un-mangled — so every list-then-read caller got `x.enc` back and either double-mangled it or failed its own extension filter. Callers cannot compensate (the extension is wrapper-private). Found by adversarial review of TD-USUB-1 segment discovery; it also broke WAL-manifest discovery under encryption, and silently broke the spill store (no segments found → no tombstones, sequence restart → every post-restart flush collides on `write_if_absent`, DROP purges nothing).
* Lesson: a wrapper that renames on write must un-mangle on `list`; "forgot `actual_path` here" was the expected bug class and the audit found it only in `list` (every other method, including `metadata`, was already correct; default `remove_dir_all` now hands `delete` a logical url). Directories are never mangled.
* The spill store's fail-closed `is_mangled_spill_segment` detector is kept as defence-in-depth for future wrappers. Inherent residual (not actionable): extension marking cannot distinguish an unencrypted file genuinely named `x.enc`; `.enc.v2`/dotless extensions are reachable only via `with_extension`, which has no callers.
* Evidence: five tests in a crate that had none, including an `exists`-probe round-trip and a direct WAL-manifest filter reproduction.
* Note: this TD first shipped in #1953 marked Open because the fix merged first in a separate PR.
