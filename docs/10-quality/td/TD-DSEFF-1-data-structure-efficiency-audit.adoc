== History

Two defect families were removed across GA hot paths: (A) per-item work proportional to store size (deep clone per access, whole-table scan per item: IVF `add_vector`/`search`, AXIS exact-filtered query, hybrid graph traversals O(V·E), extraction `ids.contains`, WAL `mark_flushed`), and (B) unbounded accumulate → full sort → truncate (now a shared bounded `TopKHeap<E: Ord>` in `proximadb-search-types::bounded_queue`, differential-proven byte-identical to stable sort+truncate). CatalogCache moved to DashMap shards + ring-sampled eviction (closing TD-CAT-5).

*Lesson that still applies:* every one of these defects passed all existing tests — fixed-size tests cannot see asymptotics, so ratchets must measure *shape*, not wall-clock.
*Rejections that still matter:* no hard beam cap on HNSW `search_layer_predicate` (it breaks the sparse-predicate full-drain recall mechanism; the shipped frontier prune is provably identical); no `lru`-crate LRU for CatalogCache (`get` takes `&mut`, reintroducing the whole-map write lock).

*Evidence (ratchets):* `tests/ivf_ingest_asymptotic_test.rs` (last/first batch median ≤ 4.0); graph hybrid 500 vs 4000 nodes traversal ratio ≤ 20; HNSW permissive-predicate parity + sparse-drain guard.
