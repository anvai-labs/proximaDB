== History (shipped)

* **Finding (2026-07-12).** The engine taxonomy was told four ways — the `StorageEngineStrategy` enum,
  the `src/storage/engines/` tree (with dirs lacking variants), `SUPPORTED_SURFACE` tiers, and design-doc
  inventories (an external analysis reproduced the partial SST/HELIX/NOVA/VIPER list). `Helix` was
  doc-commented "time-series optimized" (a TST copy-paste) though it is a Hilbert-clustered spatial vector
  engine. Lesson: when the enum, tree, support contract and docs disagree, every consumer resolves it by
  guessing — the module header is the implementation truth.
* **Fix (#915, #1107).** One matrix: every engine dir + ORION + reserved variants, each with purpose,
  tier (Supported/Beta/Experimental/Internal/Removed/Planned), variant, path and gate; the missing-variant
  question decided in the matrix (SEQUOIA internal, EVENTLOG infrastructure, UNIVERSAL not an engine).
  CHRONO/TITAN stub engines had been removed by #702.

== Remaining

  `Chrono` enum variant and the v1 proto `TITAN = 11` value are retained for wire compatibility only).

  guarded).
