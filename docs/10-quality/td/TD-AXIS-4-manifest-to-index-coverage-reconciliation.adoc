== History

Adaptive search already picks the exact PAX scan (100% recall, no index state) within the DRAM byte budget; AXIS keeps only beyond-DRAM-scale ANN, which this TD does not cover.
*Finding kept for any compact-index successor:* `IndexRecoveryManager` / `load_index_from_disk` reload *existing* index files and cannot discover never-indexed segments, and `AxisManager` holds no manifest reference, so reconciliation must be storage-driven (a mixed-read-safe coverage marker, or idempotent lazy re-emit through `handle_flushed_vectors`), triggered lazily per collection, with a metric for un-indexed segments.
*Lesson:* `FileSystem::list` is not uniform — local is single-level `read_dir`, object stores list leaves recursively — so a local-only test can pass while production silently no-ops (see TD-EVENTLOG-1 §4).
