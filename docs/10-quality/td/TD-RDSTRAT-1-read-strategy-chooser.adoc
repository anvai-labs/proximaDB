== History

Slices shipped before supersession: SST full-scan coalescing (slice 2, #783), the cost-driven tier-aware chooser (slice 3a, #786) and its wiring into both read sites (slice 3b, #791), default-off behind `PROXIMADB_STORAGE_READ_STRATEGY_CHOOSER`.
*Design principle that still applies:* never author selectivity thresholds (30/50/70%); pick `argmin(GET_cost·n_gets + byte_cost·n_bytes + cold_start·[tier==cold])` from measured `io_trace` costs, so full-scan crosses over at lower selectivity on object storage than on NVMe. Pruning (zone maps/Bloom/index) stays first; the chooser only decides how to read survivors, and must be byte-identical across strategies.
*Lesson:* TD-RDSTRAT-2 proved the chooser was wired to a reader the live PAX cascade no longer used — measure the live path before investing in a lever.
