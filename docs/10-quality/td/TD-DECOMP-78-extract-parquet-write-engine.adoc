== History

* Decision: construction belongs to the composition root — factory-constructing conveniences moved
  root-side; streaming_writer's inline `UnifiedQuantizationEngine::new` (a storage → modality hard error)
  became an injected `Option<Arc<dyn QuantizationEnginePort>>`; `None` errors only when quantization arrays
  are enabled. The builder's `build()` now requires the factory.
* `columnar/common.rs` was moved then reverted — it and `serialization.rs` are one unit needing the wider
  `StorageQuantizationEnginePort`; that shipped in link:TD-DECOMP-80-extract-columnar-serialization-common.adoc[TD-DECOMP-80].
