== History

* **Capability.** `record_embedding_consumption` no longer estimates `count * 512` input tokens; it feeds
  `record_keu_units` the provider's measured usage (local BGE ONNX keeps compute-based accrual), and the
  same seam emits the neutral event (tokens + cache split, provider/model/tenant labels) via a **local
  struct** pinned to Sandhi's published schema. The existing provider-label vocabulary
  (`victor`/`azure_openai`/`openai`/`cohere`/`byo`) keys both.
* **Boundary invariants (still binding).** Neutral units only — no dollars, SKU or tier names in the event
  or public types; KEU stays authoritative and server-side (the gateway complements, never replaces, it);
  dependency one-way (ProximaDB → Sandhi schema, ADR-060); no engine-mechanism change.
* **Decision — transport consolidation declined.** Routing embedding egress through `sandhi-providers`
  was prototyped and reverted: a single-consumer OSS abstraction ADR-067 itself deprioritized, the embed
  path would sit outside Sandhi's resilience/metering decorators, and a git dep would replace ~40 lines
  that had an in-repo template. Reopen only when all three hold: Sandhi published to crates.io; a genuine
  second consumer of the shared embedding transport exists; the embedding path enters Sandhi's decorator
  stack via its own Sandhi-side ADR (prototype kept on Sandhi branch `feat/embedding-modality`).
