== History (shipped)

Layers, named precisely: bounded **memory ingress** (drop-capable, best-effort) → immutable local
**pending segment** (JSONL+zstd) → conditional-create object PUT under `DrPathBuilder`
`_operator/io_trace/` (`ObjectAccessTier = Cold`) → Iceberg-managed Parquet warehouse. S1 added a
`set_trace_observer` seam *separate* from the billing observer and a stable `query_id` at
`instrument()`; S2b made delivery crash-aware (seal before upload, writer UUID + monotonic sequence +
content digest, conditional create with `AlreadyExists` digest verification, startup retry, hard
pending cap that stops draining rather than deleting sealed files, delivery metrics). S3 made the
durable representation a versioned `TraceEnvelope` (homogeneous `TraceHeader` + `#[serde(tag =
"modality")]` payload, unknown modality ⇒ `Other`) — **billing untouched by construction**: the billing
observer still reads the in-memory `IoTraceSnapshot`; the envelope is only the sink's serialization
view. S4 projects envelopes into a star schema (`trace_header` + `trace_relational` / `trace_exec` /
`trace_vector` / `trace_embedding`), idempotent and crash-safe (deterministic per-segment file names,
`{writer_uuid, sequence}` dedup, `_watermark.json` written only after the snapshot commits). S4b runs
compaction every `warehouse_compaction_interval_s` and once on shutdown. The compute satellite
`trace_compute` is the canonical per-engine compute-cost table (`trace_header.compute_ms_total` is a
convenience rollup).

Resolved decisions that still apply: sink-first on the flat snapshot, envelope later (the durable
stream did not block on the data-model change); `query_id` joins analytical rows,
`{writer_uuid,sequence}` identifies ingestion events; `segment_bytes` is uncompressed JSONL bytes
(do not claim 4 MiB is a multipart part).

== Current caveats (open)

* **Retention/GC:** lifecycle may retire raw JSONL only after the S4 watermark covers it. The currently
  parsed `retention_days` is inert (and `partition_by` is reserved).
* **Isolation:** default operator stream is cross-tenant and operator-only. Tenant mode means one
  tenant per object under a tenant root, not a cosmetic key partition. Governance/tenant-root
  integration is not done; tenant/date/host partitioning is not implemented.
* S2b items still to evidence: operator ACL/encryption and structural tenant-mode integration tests;
  representative hot-path/lifecycle behavior.

== Gate

Observe-only—no served-result change. In addition to existing JSONL round-trip, bounded-ingress, and
billing-never-gated tests, require:

* kill after local seal / before PUT, then restart → exactly one verified object and pending file retired;
* repeated PUT/AlreadyExists → digest match is no-op, mismatch fails closed;
* two writers with identical wall clock never collide; sequence/digest round-trip;
* object-store outage → pending metrics rise, recovery drains them; cap behavior is explicit;
* duplicate install and shutdown timeout never silently discard a sealed/pending segment;
* unsupported config rejected; active-vs-reserved config test;
* sink OFF/ON representative query p50/p95 + allocation budget, proving no filesystem/network/compress on query path;
* envelope unknown-payload/back-compat and billing input parity;
* S4 Iceberg crash/retry/dedup/schema-evolution/source-watermark round-trip;
* operator-only and tenant-root path/ACL integration tests.

NOTE: the gate list is kept whole because the shipped PRs report tests for several items (S2b
delivery, S3 envelope, S4 Iceberg) but the doc never marked individual items as met; the sink OFF/ON
p50/p95 + allocation budget and the operator-only/tenant-root ACL tests are explicitly unevidenced.

== Non-goals

Recall@k / ranking / quality-eval (stays on the sampled `predicate_diagnostics` bus); OpenTelemetry
span export; a Kafka/Avro streaming bus (ADR-066 D2/D3 rejected Avro); any change to the billing meters.
