== History

The largest single-file extraction of the engines program (the PAX block container, used 358× codebase-wide).

* Lesson: rank candidates by *what the refs point at*, not by raw `crate::` ref count. All 31 of
  block_structures' refs resolved to already-extracted crates via root shims, while the "low-coupling"
  files (block_reader, sst/swift metadata) were blocked by the unextracted root `FilesystemFactory` —
  which led to the FilesystemPort inversion in link:TD-DECOMP-75-extract-sst-swift-metadata-via-filesystem-port.adoc[TD-DECOMP-75].
