== History

The audit step was doubly unfailable (`continue-on-error: true` plus `cargo audit || echo ::warning`). Proven by a same-day
regression: #2003 bumped `rustls` to 0.23.45 (closing RUSTSEC-2026-0285), and #2004 regenerated `Cargo.lock` back to 0.23.44
and passed 83/83 checks. Only an unrelated human review noticed.

* **Fix 1 (gate can fail):** option "deny warnings + reviewed ignore list" chosen; adding to `.cargo/audit.toml` is now a visible
  decision with a rationale naming the pulling dependency. `--no-yanked` because cargo-audit has no per-crate ignore for yanks.
  Its first real run surfaced **9 live vulnerabilities** (quinn-proto x5, h2, quick-xml x2, plus unsound/unmaintained warnings);
  6 fixed in-lock, the rest baseline-ignored with reasons. Note h2 0.3.27 is production-reachable via root `reqwest = "0.11"` and
  stays ignored until the reqwest 0.12 bump; quick-xml waits on object_store 0.14.
* **Fix 2 (lockfile regressions):** compares per MAJOR line (per minor for 0.x) so a legitimate whole-line drop (#2011, rustls 0.21)
  yields zero findings; `--require-base` makes an unfetched base a failure, never a silent skip. Replays #2003 -> #2004 to exactly
  one finding. 9 tests in `tests/scripts/test_lockfile_no_downgrade.py`.
* **Lesson:** during a rebase, `git checkout --theirs Cargo.lock` is the commit being *replayed*, not upstream, so it restored the
  pre-bump lock. Resolve lock conflicts by taking the base lock and re-resolving, then diff **versions**, not filenames.
* **Accepted cost:** a newly published advisory against an unchanged dependency breaks unrelated PRs; the fix (lock bump or
  reasoned ignore) is visible rather than silent.
