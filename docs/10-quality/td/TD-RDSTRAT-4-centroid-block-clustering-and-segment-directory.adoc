== History

Filed (#899) to make the cascade selective *across* blocks: it was tier-selective within a block but ranked every block's codes, because flush wrote vectors in insertion order and there was no per-block vector zone-map. Proposed levers: cluster vectors into blocks + per-block centroid probe (B), and a single segment-level directory (A), for a ≤3-GET cold cascade.
*Lesson that still applies:* unlike byte-identical striped reads, clustering/pruning changes which candidates the coarse stage sees, so recall is the gate; recall lives in the oversampling factor, not code precision, and a cascade that skips the SQ8 middle tier silently regresses recall. Re-homed onto VOE as TD-RDSTRAT-5, whose prune route failed to hold recall and GETs together; the across-block selectivity now comes from TD-RDSTRAT-8's A0 cell probe.
