== History

The P1 of ADR-087: the composition rule enforced only on `(Some(subject), Some(stable_id))`, so an
authenticated subject in an unminted tenant passed through silently — enforcement strength equalled
mint coverage. Fixed in the mandated order, **totality before strictness**: `SystemCatalog` (WAL +
snapshot, recovered allocator floor, serialized first mint) and `NativeCatalog` mint stable ids;
`SharedServices` mints `default` before serving; ABAC provisioning mints-or-resolves the tenant
before persisting a binding. Then the rule flipped to deny at both composition points, with the full
`enforcer × subject × stable-id × auth-class` truth table pinned in a pure unit test (`AuthClass` is
audit provenance and does not weaken the deny). Flipping before the mint would have fail-closed every
unminted dev/embedded deployment.

Lesson: building the live ratchet found two composition-root defects the component matrix could not
see — pgwire did not receive the process-shared enforcer, and the default `SystemCatalog` did not
mint durable object/namespace identity (later completed under TD-AUTHZ-2). Canonical
`POST /api/v2/sql` was added as a thin single-statement adapter over the same SQL authority (no
parser/planner fork).

Evidence: `abac_relational_transport_e2e` and sibling live suites prove deny-before-provision,
row-predicate filtering, principal isolation and hot revoke across pgwire, authenticated gRPC SQL,
REST SQL, REST record search/point-get, gRPC v2 unary/streaming search + point-get, and Flight
`DoGet` vector search.
