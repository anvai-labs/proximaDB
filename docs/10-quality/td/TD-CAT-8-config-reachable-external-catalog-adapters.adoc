== History (shipped)

*Outcome.* The external adapters keep `impl Catalog` and register with `CatalogManager`, which already is
the live cross-catalog layer (`register`, `resolve_table`, `resolve_table_scoped` with structural tenant
isolation). The parallel `federation/` module (`ExternalCatalog` + `FederatedCatalog`: 0 impls, 0
construction sites, 0 consumers) was deleted (1047 lines). Per-catalog constraint-capability metadata,
if wanted later, belongs on `CatalogManager`, not a parallel type.

The TD went through six recorded corrections; the lessons still apply:

. *"Zero non-test callers"* was wrong: the adapters were public API and had proto `CatalogConfig` arms.
  Never gate/delete on a "dead code" rationale without a reachability check.
. *"Config-reachable"* was too generous: `convert_proto_catalog_config` returned `NotImplemented` for every
  arm, `Native` included. It is now `create_configured_catalog`, dispatching Glue/Unity/Polaris to the
  `CatalogManager::create_*_catalog` factories (credentials never logged); the route moved to `/api/v2/catalogs`.
. *"Move the existing bodies across"* failed for two of five: `HiveCatalog` was a HashMap **mock** (deleted,
  ~780 lines; its WAL-test use replaced by an explicit `UnlistedDefaultNamespaceCatalog` double), and
  `IcebergCatalog` is a *local* store that silently ignored a `jdbc:` URI and mapped remote warehouses to
  `temp_dir()`. Iceberg now rejects both (teeth: the rejection tests fail without the guards while
  `a_local_warehouse_still_constructs` passes).
. *"They all compile into every build"* was wrong: `pub mod` lines hide a module's inner `#![cfg]`
  (`unity`/`polaris` were already gated). `delta.rs` (1863 lines) is now gated; `oltp.rs` went to TD-CAT-10.
. *"Keep and finish federation"* was **reversed** once a consumer was looked for and none existed.
. *"CI does not exercise `enterprise-catalogs`"* was wrong; the matrix ran `cargo check` without test
  targets, so feature-gated test rot was invisible. The matrix now runs `--tests` (not `--all-targets`,
  which adds 38 benches + 23 examples and risks the documented runner OOM). Teeth: stale struct literal →
  old command 0 errors, new command E0063.

*Live authz hole closed with the path fix.* The catalog REST router was mounted at a doubled path
(`/api/v1/catalogs/api/v1/catalogs/...`) and none of its 11 handlers checked authorization; fixing the path
alone would have made the hole live. `require_catalog_operator` (`SystemAdmin` ∪ `ConfigureSystem`,
fail-closed on an absent context) now guards all 11.

*Hive proto arm retired (#1724):* field 14 and enum value 5 are reserved.

== Open

* **No CI lane compiles the root crate's examples.** Clippy is `--lib --bins`; the feature matrix is
  `--tests`. Benches are now compiled by the medium-tier `cargo check --workspace --benches` job
  (develop→qa only); the 23 examples are built by no gate. Closing it means confronting the documented
  `--all-targets` OOM, so it needs its own change with runner-memory evidence.
* **Glue no-ops silently without a client.** Each operation is `if let Some(client) = &self.client { … }`
  with **no else**, so with no client (or the `aws` feature off) it no-ops and returns `Ok` (13 sites as of
  2026-10-15). `glue.rs` module gating was left as a judgement call (it is only inert without `aws`, not absent).
* Pre-existing unused imports in `rest/canonical/catalog.rs`, visible only under
  `--features enterprise-catalogs` (not re-verified 2026-10-15).
