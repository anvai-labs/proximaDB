== First diagnostic run

A local debug run on `d4a870665` with the benchmark admission and artifact changes used
synthetic scale 0.001 and queried TPC-H Q3, Q17, Q18 and Q21. The full JSON and
partial JSONL agreed on all 16 records. The TPC-H load acknowledged 6,019 lineitem
rows in 31 batches. All four queries completed in both sweeps. The Q21 native
repeat charged 756 ms of its 760 ms wall time to native compute. The published
DataFusion sweep changed both storage and compute, and this diagnostic leaves open
which native operator accounts for the cost at scale 0.1.

A matched follow-up enabled native table registration. Repeat Q21 took 757 ms with
the default storage setup and 130 ms when the resident limit was lowered to 128 rows
to exercise spilled Layer A. Both runs used DataFusionLocal before publication.
The forced-spill run increased total load time from 1.62 s to 8.48 s. This debug
fixture identifies a query-versus-load tradeoff for further measurement. The
reported row counts agree, and typed result equality remains a separate gate.
The forced-spill configuration also completed all four queries and wrote both
ledger artifacts after the Arrow 60 and DataFusion 56 RC2 upgrade.
