== Scope

On-disk warm cache for the per-tenant system catalog, inserted between the hot cache and object storage by composition. Code comments already cite this id.

== Implementation evidence and remaining gate (2026-10-26)

`WarmDiskStore` is implemented in `crates/control/proximadb-catalog/src/syscat_warm.rs`.
`CollectionService::with_catalog_manager` inserts it when a builder directory or
`PROXIMADB_SYSCAT_WARM_DIR` is configured. Tests cover warm integration/hydration. This is
not proof of the complete per-tenant or multi-pod contract: verify durable version identity,
restart invalidation and tenant isolation before broad rollout. Coordinate TD-SC-5 instead
of treating process-local corpus stamps as a shared durable authority.
