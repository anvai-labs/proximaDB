== History

Resolution cascade: tag `workload_profile:append|bulk|churn` > env `PROXIMADB_STORAGE_PROFILE` > default `AppendBulk`; `append` and `bulk` both map to `AppendBulk`, unknown/absent defaults, last-matching tag wins (parity with `resolve_pax_vector_quant`).
*Decisions that still apply:* the resolver takes the collection's tag list (`&[String]`), not `&CollectionConfig`, so it adds no v1-proto reference (TD-123 ratchet) — tag extraction happens at the call site. `CatalogWorkloadProfile` is a deliberately distinct concern (ADR-061 D6); do not wire the two together.
