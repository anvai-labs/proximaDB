== History

Correction that still applies: the ungated `X-Forwarded-For` read was **not** a rate-limit bypass (the
REST limiter was unmounted; pgwire keys on the socket peer). The live consumer was **KOU egress
metering**: `get_client_ip` fell back `X-Forwarded-For` → `X-Real-IP` → hardcoded `127.0.0.1`
because nothing wired `ConnectInfo`. D1: any caller could send `X-Forwarded-For: 10.0.0.1` and classify
as unchargeable (`KouLocality::Unknown`). D2 (larger): with no proxy, every request became loopback ⇒
`Unknown` ⇒ the result-egress meter recorded nothing in the default deployment — a co-design dimension
structurally unobservable, not just mis-weighted.

Fix order mattered: S1 (observe the peer) is load-bearing; S2 (trusted-proxy CIDR gate, default empty,
drop-not-reject like ADR-0053 W8) is meaningless without it. Trap avoided: a Unix socket has no
`SocketAddr`, so UDS gets an explicit `LocalSocketPeer` marker — otherwise "UDS" and "TCP surface that
forgot the wiring" collapse into one `Unobserved` state; a variant nothing can produce is
indistinguishable from one left unimplemented. Flight (`remote_addr()`) and pgwire (`peer_ip`) were
already correct.

Non-goals recorded: RFC 7239 `Forwarded`; proxy chains deeper than 1 (leftmost XFF entry taken).
