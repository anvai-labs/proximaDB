== History

* Compaction now runs on the (previously built but idle) `schedule_compaction` → `worker_loop` machinery; `run_due_compaction` remains as the inline/test primitive. Shipped with TD-COMPACT-7/8 as the ADR-076 D1 producer/consumer loop; `background_thread_count` is wired to the worker spawn (was hardcoded 2).
* Lessons that still apply:
** The per-output `active_compactions` dedup must be inserted at **enqueue** time under the same write lock as the check — inserting at worker time left a TOCTOU where two rapid schedules both passed.
** Background workers must carry the ADR-046 atomic-swap coordinator (`with_atomic_coordinator`); `Compaction::new` passes `None`, which would publish compacted segments non-atomically.
** Worker state (active marker + TD-COMPACT-8 `training_in_flight`) must be released on **every** exit path (`release_task_state` on Ok/Err/construction failure).
* Evidence: `td_compact6_schedule_dedups_same_output_at_enqueue`, `td_compact6_worker_clears_training_in_flight_after_completion`.
