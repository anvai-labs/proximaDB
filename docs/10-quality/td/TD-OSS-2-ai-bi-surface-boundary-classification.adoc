== History

The modules survived B4's externalization of `src/{revenue,sales_enablement,licensing,executive}` only because they lived under
`src/ai/`. `check_oss_boundary.py` did not cover their terms, so **the guard passing was silence, not a verdict**. A reachability
audit found their only consumers were each other and a default-OFF `ai_endpoints` handler. That handler **could not compile when
enabled**: an immutable `router` was reassigned, which stayed invisible because the feature matrix never built the feature. It also
found a never-compiled test file (`release_1_enterprise_validation.rs`, absent from `mod.rs`). Lesson: an unbuilt feature flag hides
dead code; dormant scaffolding is removed, not renamed (pre-GA).

Kept as product features: `insights.rs`, `analytics.rs` and the NL-query stack (live consumers). No `check_oss_boundary.py` denylist
terms were added, because "business intelligence" naming inside retained feature content would false-positive.
