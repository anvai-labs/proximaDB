== History

The insight: round-trips are set by how many *disjoint byte ranges* probed cells occupy, not by how many cells are probed, so placing near centroids adjacently coalesces probe sets (recall is provably invariant to ordering).
*Lesson:* a code audit falsified the premise — `cluster_order_pca_ivf` already emits cells in Hilbert order of the projected centroid and v3/A0 preserves it; the 51-GET measurement predated the default-on A0 route. Check the shipped writer before filing an ordering lever.
*Current control to beat:* 81.4 GETs/query vs 108.5 unprobed at recall 0.986–0.987.
