== History

Agent-driven code-RAG is update-heavy and freshness-critical. *Decisive finding:* the unflushed delta is already hard-bounded (~2 MiB by default), so a Strong brute-force merge of it is the smallest correct mechanism; a second mutable index would add insert/evict/flush/replay coherence for a large-delta state the bound excludes. WAL/`ProximaRecord` stays the sole durable authority and compaction clustering stays off for `Churn`. Revisit an index only under a new evidence-backed TD showing the bounded delta dominates latency; use the existing TD-045 fusion seam for graph expansion.
*Evidence:* `tests/storage_wlp_churn_freshness.rs` — `test_churn_reembedded_symbol_immediately_visible` (new embedding visible before flush; WAL replay reconstructs identical state) and `test_append_collection_unaffected_by_churn_path`.
