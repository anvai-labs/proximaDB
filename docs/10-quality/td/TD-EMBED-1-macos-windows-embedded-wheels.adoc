== History

* **Capability.** All three platforms ship embedded wheels from one matrix; `publish-embedded-pypi`'s
  `*embedded-wheels*` glob collects them with no publish-side change. Intel macOS is intentionally not
  built (aarch64 covers Rosetta). The `windows-compile-ratchet` workflow (rungs 1–3 gating: storage-common,
  root lib, root lib + `python` + C-deps) fails the introducing PR on an MSVC regression.
* **Lesson — measure the real build, not a grep.** The feared "multi-week unix→MSVC port" with a
  `PlatformFile` seam was a misdiagnosis from a grep conflating cross-platform `memmap2` with unix-only
  APIs; the genuinely unix-only code was 3 files, all already `#[cfg(unix)]`-gated. The real blockers
  were isolated oversights (`memmap2::Advice` → no-op off unix, Unix-domain sockets, the python/C-dep
  tail), fixed as `#[cfg]` gates that leave the unix path byte-identical.
* **Lesson — no `target-cpu=native` in distributable builds.** It broke `ring` on the macOS runner
  (`CAPS_STATIC` assert) and would bake builder CPU features into the wheel (SIGILL risk); dropped for
  `aarch64-apple-darwin`.
* **Evidence.** `maturin` dry-run built `proximadb_embedded-0.2.2-cp310-abi3-win_amd64.whl` on
  `windows-2022`; macOS dry-run imports (originally on `macos-14`; `macos-15` since the
  image's 2026-11-02 retirement, PR #2307).
