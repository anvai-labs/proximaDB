== History

The persistent L2 tier (#1325) counted hits/misses only in process-local stats, so the warehouse and
the fleet-priors cold/warm classification (keyed on the footer ratio) could not see it. Finding that
still applies: with a persistent tier, **footer-cold no longer implies cold** — a fresh process can be
footer-cold yet L2-warm, paying near-warm GETs while the footer ratio classifies it cold, skewing
cold-cell priors. The counters are additive alongside the footer counters (mixed-read-safe; old
envelopes deserialize; billing untouched — the cache crate stays layering-clean via an engine-layer
`L2ValueStore` adapter). Evidence: `l2_probe_outcomes_reach_the_ambient_io_trace`.
