== History (shipped)

First *unconditional, real-auth* ABAC enforcement: gRPC `ExecuteQuery` captures
`grpc_auth::user_id(&request)` and threads it through both SQL port traits into `try_run_select`.
Design decision that still applies: the runtime port carries an opaque identity (`Option<&str>`,
later `PortIdentity`) because `proximadb-runtime` cannot name `SubjectId`; the `String → SubjectId`
lift happens at the root-crate boundary (`QueryFacadeAdapter::execute_sql`), keeping the feature gate
and catalog types inside the root crate (no cfg-on-`async_trait` risk).

Evidence: `abac_relational_transport_e2e` — live API-key-authenticated gRPC deny-before-provision →
permit → other-principal deny → hot revoke. Canonical `POST /api/v2/sql` was later added over the
same typed port (TD-ABAC-11). Durable epochs / column masking / graph trio moved to TD-AUTHZ-1 L2.5;
pgwire SCRAM shipped as TD-PGWIRE-AUTH-1.
