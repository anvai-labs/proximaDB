== History (shipped)

* **S1/S1a (#1670).** Span-first offsets across five files; sub-minimum spans merged instead of dropped;
  `_preserve_special_blocks` rewritten as one forward span pass; CJK lookahead fixed; quadratic
  accumulators removed. `start_pos`/`end_pos` are persisted, so the `offset_basis`/`offset_contract`
  markers shipped additively — absence means legacy, no flag day.
* **S2 (#1679).** `BoundarySource` proposes `(span, kind, meaning)`; one `Segmenter` consumes candidates
  plus a `TokenBudget` and returns a total partition. `StrategyBoundarySource` adapts every existing
  strategy so the enum survives as the facade; `RECURSIVE` disappears as a concept (its sentence tier was
  provably unreachable). `max_chunk_size` is now enforced by wrapping `chunk` at class definition
  (split, never raise or pass through) — its first version silently narrowed `CodeChunkingStrategy.chunk`'s
  signature, caught by the pinned control: a guard that changes the API it guards is worse than none.
* **Port earned its keep before migration.** `NativeSentenceBoundarySource` (TD-CHUNK-3 item 3) swapped the
  sentence grid to Rust without touching the segmenter, and made the upstream splitter's unclamped
  `overlap=128` (a 4.3× KEU multiplier) unreachable, because a boundary source has no budget to pass.
* **Lessons.** (a) Composing nested structures buys nothing: on header-dense Markdown paragraph ends are
  a strict subset of sentence ends (80 of 81); demonstrate composition on `prose` (522 vs 61). (b) The
  segmenter resolves candidates at token granularity, so a heading source moves few cuts — it is worth
  adding for the hierarchy path it carries, not the positions it proposes.

== S3 — migrate the consumers (open; out of this repository)

anvaiops drops its `_PDB_STRATEGY` translation table and `HEADING` becomes a boundary source; fix its
hardcoded `source_id="doc"` while the seam is open (today every document in every tenant emits colliding
chunk ids). victor-rag consumes the port; its HTML/JSON sources need **reimplementation, not lifting**,
because their offsets are fabricated.

* **Not blocked on this repo.** The port, the facade, the invariant suite, the corpus and the eval
  harness are all landed and importable. A consumer can migrate today.
* **What this repo should NOT do:** re-export the port from `victor_contracts` speculatively. ADR-091
  D2 asks for the mirror, but a neutral name with no consumer is the same "built and never called"
  shape this whole program exists to remove. Mirror it in the PR that migrates the first consumer.

== Acceptance

TD-CHUNK-1's eight properties green across every source set × corpus entry; the trace reports
`bytes_covered == bytes_in` and `spans_dropped == 0` corpus-wide; anvaiops and victor-rag run the shared
suite through the port; chunk count per document does not regress against the TD-CHUNK-1 baseline.
