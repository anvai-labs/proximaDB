== The defect

A *capability facade* is a function, type or config variant whose **name,
signature or documentation promises a capability its body does not implement** —
usually while a real implementation of that capability exists elsewhere in the
workspace. It is worse than a missing feature because the caller cannot tell:
everything visible reads as working, so the next integrator wires it and ships
the consequence.

Canonical example (TD-BLOOM-1, before this TD's PR):

[source,rust]
----
fn check_bloom_simple(&self, bloom_data: &[u8], key: &[u8]) -> bool {
    // Simplified bloom filter check
    // In practice, would use proper bloom filter implementation
    let hash = self.hash_bytes(key);
    bloom_data[(hash % bloom_data.len() as u64) as usize] != 0
}
----

…probing bytes that were the file's header, consumed as "definitely absent →
skip the file", while `proximadb_bloom::SstableBloomFilter` was imported into the
very same struct and never populated.

== Severity model — liveness decides, not shape

The same facade is a bug or debt depending only on whether anything reaches it.
Three tiers; every entry below is graded by a traced call chain, not a name-grep:

[cols="1,3"]
|===
| **Live-path** | Production callers reach it. A bug *now*.
| **Public-uncalled** | Zero callers, but `pub`, documented as working, often named identically to a live sibling. A **trap**: the TD-TENANT-4 "built-never-called" class — the integration that activates it is one line and looks safe.
| **Private/dead** | Unreachable and not advertised. Debt.
|===

The **failure direction** matters as much as the tier. A facade that answers
*conservatively* (never prune, cannot skip, `Err`) costs performance at worst. A
facade that answers *permissively* — claims absence, claims presence, claims a
prune or a save happened — produces wrong results or lying metrics. The model
for a legitimate deliberate narrowing is
`src/cluster/partition_lease.rs` `LockIntent::is_compatible_with`: it returns
`false` for every pair (conservative) and its doc says exactly why ("MVP DML
locking uses the existing single-holder object-store lease … intentionally not
claimed here"). Conservative answer, stated reason — that is not a facade.

== The founding finding: bloom pruning

**Bloom-filter pruning was advertised across four storage engines and
implemented in none.** Fixed in this TD's PR (all now conservative or refusing;
no wire/format change):

[cols="1,3,2"]
|===
| Site | Facade | Now

| SST `proximablocks/sst_metadata.rs` `can_skip_file`/`check_bloom_simple`
| Probed the file's magic+header (read from offset 0) as a filter; `0x00` ⇒ skip file. `DefaultHasher`; two panic sites. Public-uncalled.
| Branch + probe + fabricated 4 KiB read removed; header reports 0/0. See TD-BLOOM-1.

| HELIX `helix/readers.rs` `check_bloom_filter`
| Built a filter around stored bytes with **invented** `(bits_per_key=10, expected_items=10000, ByteAligned)`. Unreachable: every writer sets `bloom_filter: None`.
| Bytes-present arm returns a typed error instead of guessing.

| SWIFT `swift/proximablocks_compact_reader.rs` `should_read_superblock_bloom`
| A `size > 0` test wearing a bloom name; returned `true` into a path whose next step always errors. Its three siblings honestly said "not yet implemented".
| Returns `false` (claims nothing).

| RAPTOR `raptor/artus_bloom.rs` `serialize_bloom`
| Wrote an **all-zero** bitmap (`BloomFilterStrategy` exposes no bit accessor) ⇒ a correct filter deserialised to "absent for every key". Dead (tests + `experimental-engines`).
| Returns an error.

| SST IO `proximablocks/sst_io_layer.rs` `check_bloom` / `find_block_for_key`
| `check_bloom` was `true // Placeholder` (safe, but named as a filter). `find_block_for_key` returned block 0 for every key; its `None` arm would have reported existing keys absent **and** credited `stats.bytes_saved`. Zero callers.
| Renamed `bloom_might_contain_unfiltered` (documented conservative); `find_block_for_key` errors.

| DataFusion `engine_adapters/sst_adapter.rs`
| Set `bloom_filter = Some(vec![])` — an empty `Some` is not `None` to a pruner.
| No longer set.
|===

**The "real implementation" is itself partly a facade.** `crates/foundation/proximadb-bloom/src/lib.rs`
has real filter machinery (`SstableBloomFilter`, FPR sizing, serialize/deserialize,
`murmur3_32`), but its `hash::xxhash64` and `hash::cityhash64` are self-declared
placeholders ("Simple placeholder - in production, use xxhash-rust crate"), and
`cityhash64`'s doc calls it "FNV-1a" while the body is neither. The guard found
this; it falsified the claim, made while planning this TD, that the crate was
"complete". Building real bloom pruning must use `murmur3_32` or replace those
two first.

== The guard

`scripts/count_capability_facades.py`, modelled on `count_silent_failures.py`.
It counts **self-declared non-implementations** — a facade marker
(`placeholder`, `not (yet) implemented`, `in a real implementation`,
`in practice, would`, `would use/implement/need/require`, `simplified`, `stub`,
`for now,`/`for now.`, `won't work in production`) in a function's doc or body,
across non-test Rust under `src/`, `crates/`, `apps/`. Bidirectional ratchet
against `docs/_internal/roadmap/CAPABILITY_FACADE_BASELINE.json`; `--callers`
adds an advisory triage hint.

Calibrated against ten hand-confirmed facades (2026-11-05): catches all 8 that
self-declare; misses the 2 that do not (`tokenize_simple`,
`should_read_superblock_bloom`). Body shape is deliberately *not* a filter —
the motivating `check_bloom_simple` has three real statements, uses its
parameters and returns an expression. `TODO` and `Deferred:` are deliberately
excluded (they mark future enhancement of working code; `Deferred:` alone
inflated the count 696 → 1195 without adding a real defect).

Baseline at introduction: **992 sites**. That number is the finding: roughly a
thousand places in non-test Rust where the code says, in its own comments, that
it is not what it is named. The ratchet does not certify that none remain — a
facade that does not admit itself is invisible to it — it raises the cost of
adding one and makes every removal visible.

== Direction

. Burn down the **public-uncalled** tier first: each is one line from becoming a
  live bug. For each: implement it, delete it, or make it refuse
  conservatively with a stated reason (the `partition_lease.rs` model).
. Trace the two *(inferred)* live items (SST `vector_by_id`;
  `get_accessible_collections` consumers) before grading them further.
. Real bloom pruning is a separate feature build under CLAUDE.md #8 (see
  TD-BLOOM-1 "Still open"), and must not use the placeholder hashes above.
. Every PR that removes a facade lowers the baseline in the same commit.
