== History

The struct exporter rendered `proximadb_queries_total 0` etc. from structs never populated on live
paths, so operators checking `/metrics` first saw zeros and thought the system was broken — and real
counters with the same names would have collided. The admin UI only ever fetched `/metrics/prometheus`
and `/metrics/json`. `SystemMetrics`/`QueryMetrics`/`StorageMetrics` remain for `/metrics/json`; their
wire-or-retire decision is tracked in TD-METRICS-1.
