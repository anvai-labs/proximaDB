== History

A 2026-07-12 audit found the VOE directory built-but-dark on PAX (emission never fired, no per-block centroids, the cascade ignored the directory). Shipped default-OFF: sort-by-code clustering + per-block centroids at PAX write (S1, #908), VOE emission on flush (S2, #911), directory-fed centroid probe-prune in the cascade (S3, #914), a real SIFT prune-engaged recall ratchet (#945), and the `oedir/` parent fix that re-engaged the prune on local fs (#954). The prune could not meet recall and GET gates together, so ADR-062/065 replaced the route.
*Principles absorbed by the canonical region caches (still apply):* immutable segments make segment-keyed cache entries never stale; populate caches write-through at flush rather than read back what the writer computed; do not add a parallel cache plane — fold residency into the byte-budgeted, tenant-metered `proximadb-cache`; the directory is advisory and the WAL is the authority (ADR-020).
