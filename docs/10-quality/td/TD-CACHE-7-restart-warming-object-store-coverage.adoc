== History (shipped)

Restart warming is what makes a stateful serving tier survivable on Spot, and it lives or dies at the
object-storage write/read boundary — which had no test. Two cloud-scheme regressions slipped through
reactively (TD-FLUSH-6 / #1216 container dropped from cloud URLs; TD-CACHE-5 / #1218 malformed
`///manifests/` prefix). S1 locks the boundary: `manifest_url_is_well_formed_on_cloud_bases`
(always-on; `azure://`/`s3://`/`adls://`, container preserved, no `//` run, tenant-scoped
`…/warm_cache.json`) and `warm_manifest_round_trips_on_object_store` (`#[ignore]`, cloud-emulator
tier, `PROXIMADB_WARM_TEST_BASE`). Empirical 2026-07-26: the round-trip PASSES on develop + Azurite —
the bed failure was a stale binary. Lesson: "treat the boundary as the contract" (co-design #3) means
the boundary needs its own test, not just the unit around it.

== Open (S2)

An end-to-end warm-restart on object storage (server SIGTERM → manifest on
azure → replacement server → measured GET-avoidance on replay) — the #1187
E2E, re-run on `azure://` instead of `file://`, to close the last gap
between "the boundary round-trips" and "the feature delivers its GET
savings on cloud".
