== History

One small `Copy`-cheap `PortIdentity` (with `PortIdentity::anonymous()` for internal/test callers)
replaced the per-method triple, so new enforcement surfaces build the struct instead of re-rippling
every port impl, and the triple can no longer drift apart (a `subject` without `tenant_stable_id`
silently disabled policy resolution).

Decision that still applies: **do not collapse identity to `tenant_stable_id` alone.** The tenant
string is the sole authoritative component (catalog + `DrPathBuilder` are string-keyed, ADR-0083
composite); the u64 is a derived policy key. Collapsing to it would reintroduce the reverse-lookup
drift seam ADR-0083 retired.
