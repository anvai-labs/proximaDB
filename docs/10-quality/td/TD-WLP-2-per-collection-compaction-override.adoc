== History

Shipped cascade: a truthy global env force-arms (unless a collection explicitly opts out); an explicitly falsy global env is the master hard-disable; `compaction:on|off` is the per-collection override; otherwise the profile default applies (`AppendBulk`, including untagged, armed; `Churn` off).
*Decision that still applies:* do not extend this TD with another threshold heuristic — a fixed count cannot decide whether rewrite cost repays measured GET/byte/cache savings across dimensions, providers and query/write ratios; that is TD-RDSTRAT-9's observe-first controller.
