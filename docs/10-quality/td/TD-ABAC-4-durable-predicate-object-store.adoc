== History

Third durable half of the ABAC substrate (authority #1310 + bindings #1331 + predicate objects).
Before it the production predicate store was an empty `InMemoryPredicateObjectStore`, so any binding
with a `predicate_ref` resolved to the fail-closed unsatisfiable deny — production ABAC could only do
table-level permit/deny. Persisted as atomic temp-file+rename JSON at
`<data_dir>/abac/predicate-objects.json`.

Decision that still applies: the store is keyed by **global `ObjectId`, not tenant-partitioned**;
tenant isolation comes from the tenant-scoped bindings that select which refs apply. TD-AUTHZ-1 L2.3
later confirmed this is not an escalation (writes are operator-only) and pinned it with
`predicate_objects_are_cluster_scope_not_tenant_scoped`; reopen only if a tenant-facing policy API is
added.

Remaining follow-ons moved: durable policy epochs and column masking → TD-AUTHZ-1 L2.5;
gRPC/REST subject threading → TD-ABAC-5 (done); pgwire SCRAM → TD-PGWIRE-AUTH-1 (done).

Evidence: `fs_predicate_store_objects_survive_a_restart` (refs resolve identically and
`compile_security_filter` works post-restart; missing ref stays fail-closed).
