== History

A bare correlated scalar aggregate already decorrelated into a `LEFT JOIN` over a `GROUP BY`; the only gap for Q17
(`l_quantity < (SELECT 0.2 * avg(l_quantity) … WHERE l_partkey = p_partkey)`) was the arithmetic wrapper.
`single_aggregate_call` extracts the one aggregate from the arithmetic spine; `build_scalar_over_agg` rebuilds the
wrapper over the post-join value column (valid because the `LEFT JOIN` keeps outer columns first). Correlated
`COUNT` still declines by design (empty-group NULL-vs-0).

Evidence: `tests/rel_correlated_scalar_arith_e2e.rs`; frontend unit `correlated_scalar_aggregate_allows_arithmetic_wrapper`; Q17 native row-exact.
