== History (shipped)

The reference MCP surface (ADR-037 D5; `proximadb-mcp` #440, Stage 1a #470, Stage 1b #630) shipped five live data tools. The three
agent-state tools initially returned "not yet wired". **Finding (2026-07-02):** this was not a tail-end wire-in. No production
`AgenticGrpcBackend` or `AgenticRestBackend` existed (trait + test-only mock, unmounted), and the primitives were heterogeneous:
memory ingest is LLM-driven (TD-101, `501` without an LLM), there was no checkpoint store, and `EventLogEngine` had no
agent-facing composition.

* **MCP-1a — event** (#639): `EventLogEngine::append_event` behind the MCP `event` tool.
* **MCP-1b — memory search** (#647): scoped semantic search over `VectorMemoryStore`.
* **MCP-1d — checkpoint** (#1276, 2026-07-28): *not* as predicted. The "embedded `save_checkpoint`" premise was stale (no such store
  existed), and it needed no new engine or LLM. `AgentCheckpointStore` (`src/services/agent_checkpoint.rs`) is **event-sourced over
  the existing `EventLogEngine`**. Its entity id `agent-checkpoint:{tenant}:{ns}:{thread}` makes tenant isolation structural
  (fail-closed on empty tenant, `:` injection rejected). It has 20 unit tests. `EngineBackend::not_wired` lost its last caller and was deleted.

== What "done" requires (prerequisite work)

. A **wired production agentic backend** — one impl (gRPC and/or REST) composed over
  the real stores and constructed at server boot (registered, not test-only). This
  is the single missing seam both the gRPC and REST agentic surfaces already assume.
. **LLM availability** for `memory` put/ingest (TD-101) — the `501`-guard path must
  resolve, or the MCP `memory` put tool must degrade explicitly when no LLM is set.
. ~~A **checkpoint store** promoted from embedded-only to a server-composed service.~~ Done by MCP-1d (greenfield, event-sourced).
. Then `EngineBackend` gains a handle to that backend (threaded through
  `SharedServices`, like `api_handlers` / `query_adapter`) and its
  `memory`/`checkpoint`/`event` methods call it directly in-process.

== Open phase

* **MCP-1c — memory put** (LLM-gated): compose `MemoryWriteEngine::ingest`; the MCP
  `memory` put path degrades explicitly when no LLM is configured (TD-101).
