== History

Proposed splitting each segment into a Hot coarse object (header + footer + A0 + RaBitQ, ~16 MB at SIFT 1M) and a Cool-tier rerank object (SQ8/fp32, ~98% of ~763 MB), so the tier could be applied per temperature and the coarse part pinned whole in DRAM.
*Why rejected:* it breaks the one-PUT / one-object compaction CAS contract, doubles object count and the orphan-recovery surface, and its cache premise predates the shared survivor pool; the multi-object publication/recovery and Cool-tier read penalties were never measured. The ~16 MB vs ~763 MB figure is an estimate, not acceptance evidence.
