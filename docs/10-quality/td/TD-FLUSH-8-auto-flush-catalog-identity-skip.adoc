== History (shipped)

* Symptom (ADR-089 P1 evidence run, 2026-08-06): the ADR-069 driver's periodic tick logged `no catalog metadata for '1', skipping` every cycle for a REST-v2 collection with unflushed data.
* **Corrected diagnosis — lesson:** the original filing over-claimed "REST-created collections never reach PAX". Inline size-flushes worked (the "0 segments" was the corridor benchmark deleting its collection in `close()`), and both sides used the same ADR-031 decimal `object_id`. The real bug was two catalog **read paths** disagreeing: the driver's `list_collections_from_catalog` relied solely on `list_namespaces(None)`, while the write path always adds `["default"]` and has a `resolve_table` fast-path. In a namespace-listing gap the periodic (RPO and capacity) flush was skipped forever.
* Direction (owner): **the catalog is the identity authority** — no catalog-less fallbacks; test fixtures must register collections through the real catalog path.
* Fix (#1523): both flush-side functions enumerate namespaces like the write path (`list_namespaces(None)` + guaranteed `["default"]`, dedup by id); the driver falls back to per-id `resolve_collection_from_catalog`; if both miss it emits `proximadb_wal_flush_catalog_unresolved_total{collection}` and `tracing::error!` (an unresolvable WAL id is a durability incident, not a per-tick WARN). Tests: `td_flush_8_catalog_walk_tests`.
* Evidence: ADR-089 P1 A/B on a persistent 80k collection — filtered p50 128 ms → 63 ms through REST.

== Remaining follow-up

* End-to-end regression harness through the REAL catalog + driver tick:
  REST-create → ingest below the size trigger → let the TIME (RPO) trigger
  fire → assert a `.pax` segment exists under the collection's
  `DrPathBuilder` path (no `force_flush`/`materialize_collection` shortcuts —
  existing tests use those entry points and masked this bug; no
  `AutoFlushDriver::tick` test existed at all).
* Sweep other callers of the free functions (`recovery_manager.rs`,
  `database.rs`) for the same weaker-walk assumption — they now inherit the
  fixed walk automatically, but their skip-handling should be reviewed for the
  same fail-loud treatment.
