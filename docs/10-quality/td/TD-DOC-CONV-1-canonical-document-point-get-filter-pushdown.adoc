== History

* **Capability.** A new `VectorOperationsService::get_full_record_with_tenant_context` (tenant- and
  dead-record-filtered) → `RecordOpsService::handle_record_get_full_for_tenant` →
  `RecordRoutePort::get_record` serves document point reads; on miss it falls back to the legacy map
  (mixed-read-safe). `CANONICAL_DOC_SCAN_LIMIT` survives only on the genuine bulk paths
  (`query_documents`/`aggregate_documents`), so the point-read silent-truncation risk is gone.
* **Decisive finding.** The shared surface lacked a *labelled* point-get: `RichSearchResult` drops
  `labels`/`variation_id`, which the document projection needs. The fix was not an id-keyed scan
  predicate but returning the full record `UnifiedSstableReader::vector()` already looked up — the SST
  branch had been reconstructing a label-less record (additive change: callers gain `labels`).
* **Evidence.** Convergence e2e get/round-trip tests pass through the point-get path.
