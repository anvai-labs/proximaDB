== History (shipped)

`compression_common` (105 intra-ops refs) had exactly one outgoing root ref: control-tier
`metrics::compression::CompressionData`. Hoisting that 5-variant enum to `proximadb-compression` (metrics keeps a
re-export) let `compression_common`, `compression_adapter`, `proxima_tensor_encoding` and `simd_config` move,
with root `ops/mod.rs` shims for 8 external consumers. It also removed the last storage → control naming
dependency in the compression path.

* Lesson ("root clippy allows don't travel"): crate-level lint allows in the root do not follow moved code —
  `SIMDConfiguration::init_with` had to box its error for `result_large_err` (zero callers, so harmless).
* Evidence: nextest engine-core + metrics + compression 283/283.
