== History (shipped)

The survey found both blockers already dissolved: `proximadb-quantization-kernel` already implemented
`StorageQuantizationEnginePort` (the serializer calls only `quantize_batch`), and `crate::compute::quantization`
was already a shim. The serializer now takes `Option<Arc<dyn StorageQuantizationEnginePort>>` via
`with_quantization_engine`; root NOVA builds the concrete engine through `root_storage_quantization_engine()`;
`common.rs` filesystem fields became `Arc<dyn FilesystemPort>`.

* Behavior note that still applies: the old serializer built an engine whenever `config.quantization` was
  set and computed quantization *stats* even with enable-flags off; the injection seam preserves that.
* Evidence: engine-core nextest 190/190.

== Open: phase-7 residue

Columnar core quartet (schema, config, serialization, common) now fully lives in
engine-core/storage-common. Root's columnar dir is down to the query engine, IO layers, hybrid writer,
and metadata collectors — all phase-7 candidates.
