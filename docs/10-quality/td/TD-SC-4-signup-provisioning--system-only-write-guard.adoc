== Scope

provision_tenant_system_catalog at signup plus a system-only write guard for _syscat/*.

== Implementation evidence and remaining gate (2026-10-26)

`provision_tenant_system_catalog` in `src/services/collection/manager.rs` creates the
tenant-prefixed default namespace idempotently, with tests. The review found no non-test
caller. Wire it into the real signup/onboarding lifecycle and prove retry behavior there;
separately prove the `_syscat/*` system-only write guard across all mutation facades. Helper
tests alone do not close signup integration or authorization.
