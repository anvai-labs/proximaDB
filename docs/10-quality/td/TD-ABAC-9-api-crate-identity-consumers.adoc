== History

The api crate could not name the root-crate REST identity Extension (layering wall), so the hybrid SQL
route was the last live REST surface delegating a `None` subject. Once TD-ABAC-8 made
`ResolvedRequestIdentity` a foundation Extension, the fix was mechanical. Lesson kept: the root-crate
`execute_sql` handler in `canonical/handlers.rs` was **unrouted dead code** (verified 2026-08-02) — fix
the route that is mounted, not the one that looks canonical.
