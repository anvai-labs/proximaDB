== History (shipped)

* **Defect 1 — the route stamp lied.** With `PROXIMADB_DF_PAX_READER` on, `route_select_inner`'s `(true, false)` arm stamped `DataFusionLocal`, but dispatch requires `parquet_backed`, so Volcano served the query and `io_trace::record_route` fed Volcano's latency into DataFusion's route-cost EWMA cells — a poisoned cell is indistinguishable from a legitimate one. **Invariant that still applies: a stamp records what executed, not what was decided; a decision that cannot be honoured must not produce a cost sample.** Fix was deletion, not repair — the gate could not make DataFusion execute, so it only lied; the false `RouteAxis::Trust` claim and the duplicated scheduler-side `pax_reader_enabled()` went with it. An arm may return once DataFusion genuinely executes the shape (the bar `native_registerable` meets). Pinned by `pax_backed_olap_stamps_the_backend_that_actually_serves`. No cost-cell invalidation was needed: the gate is default-OFF and unset in CI/qa/shipped configs (operators who enabled it locally should clear their model).
* **Defect 2 — Iceberg publish failure was a `warn!` only.** Deliberately still non-fatal (Parquet data and catalog layout are complete, the catalog does not advertise Iceberg, and failing would force an O(table) re-publish), but no longer silent: `error!` plus `proximadb_warehouse_iceberg_publish_failures_total`, lazily and tolerantly registered so observability never takes down the write path.
* **Defect 3 — dead parallel Iceberg implementation.** `src/storage/formats/open/iceberg.rs` (1507 lines, zero non-doc references) deleted, with the module docs that still claimed "Iceberg ✓ Implemented"; the live implementation is `crates/storage/proximadb-iceberg-engine`.
* `TableRecordStoreRoute::ParquetIcebergStorage` → `RelationalStorage`: the slot holds the canonical WAL store; publication is the separate `MATERIALIZE` step.
* **Lesson (recurrence):** a test encoded the defect (`pax_backed_shape_routes_to_datafusion_under_gate`) and was found only in CI — the dependant search was scoped to `tests/` and `compute_scheduler.rs`. A behaviour-removal change must sweep all of `src/` and run the full `--lib` suite, not a filtered one. The test was rewritten to assert the truthful property, not deleted.

== Open

The evidence gate asked for a test where "an external reader sees either a valid manifest or an
explicit error". That test is not written, because it needs a real external Iceberg reader in the
loop to be meaningful, and a mock asserting our own counter incremented would prove nothing about
the external contract. This change removes the silence; proving the interop contract end-to-end
belongs with the Iceberg interop test lane.
