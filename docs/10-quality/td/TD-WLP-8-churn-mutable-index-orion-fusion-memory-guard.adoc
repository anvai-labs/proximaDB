== History

The gauge samples and emits at the `Churn` *read* seam (where the profile is already resolved), keeping it disjoint from the PAX layout; it is advisory and creates no write-path or query-routing authority. `Churn` remains opt-in even under the arm-defaults amendment; `AppendBulk` is untouched (asserted); WAL stays the sole durable authority.
*Decisive finding:* measuring the bound invalidated the mutable-index premise — the write path's backpressure keeps the unflushed set at ~2 MiB, so a second projection would optimize a state that cannot occur; the graph-fusion premise was also stale because `/rag` already correlates by `oid`. A new mutable index needs a new TD proving the bounded-delta assumption no longer holds.
