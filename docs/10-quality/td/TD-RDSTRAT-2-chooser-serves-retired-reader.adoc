== History

The TD-151 coalescing and TD-RDSTRAT-1 chooser were wired into the ProximaBlocks `.sst` reader, which the write path no longer produced (ADR-049 M1-3 folds every non-Arrow flush to `.pax`); the live PAX cascade read each segment whole in one `fs.read()`. The per-block `io_trace::record_range_gets(1)` calls in the cascade were *logical* projections, not physical GETs.
*Lesson that still applies:* this was found by measurement plus a backtrace probe at the `io_trace` funnel, not by reading the wiring, which looked plausible in isolation; also distinguish logical cost projections from physical GETs in traces.
*Evidence:* `tests/rdstrat_get_count_measurement_test.rs` (since retired, #1024) — N=200k, four arms (default, obj-economy hint, chooser env, scan-kill env) all identical: 640 logical `range_gets`, 110 MB, byte-identical top-k.
