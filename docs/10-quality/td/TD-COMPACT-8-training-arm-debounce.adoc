== History

* Finding: the TD-COMPACT-5 training arm fired on every flush while any untrained L0 ≥ 32 MB existed — 5–7 times in one 173 s ingest, re-training the same growing segment.
* Decision (cross-model review): a state flag is race-free and self-tuning to any ingest rate; a fixed timer is a heuristic. The training arm skips re-arming while the collection's `storage_url` is in `training_in_flight`; the count arm is unaffected.
* Lesson: once compaction became async (TD-COMPACT-6) the inline caller can no longer clear the flag — it is shared (`set_training_in_flight`) with the worker, which clears it via `release_task_state`; the flush caller clears it only on no-worker paths (nothing due, enqueue `Err`).
