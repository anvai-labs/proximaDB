== History

The entire CDC subsystem (event, transform, error, metrics, sinks, outbound, config, offset, source,
connectors, coordinator) is in the integration-tier `proximadb-cdc` crate. Root `src/cdc/mod.rs` is
`pub use proximadb_cdc::…` shims only (verified 2026-10-15).

* Vein order was dependency order: seed a dep-free leaf (`event`), then subgraphs whose only non-self
  refs were already moved, then prerequisites (`config`/`offset`/`source`) before their dependents.
* Running total at this point: ~428 tests out of the root lib binary.
