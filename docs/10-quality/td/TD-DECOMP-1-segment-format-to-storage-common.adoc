== History (shipped)

`SegmentFormat` / `SegmentFormat::detect` / `is_pax_segment` now live in
`storage-common::segment_layout`, and the PAX-decode body of the read router is the pure
`pax_block::read_pax_segment_records`. The root keeps a `pub use` of `SegmentFormat` and a thin
`read_segment_records` router (legacy branch → `ProximaDataBlock::deserialize`) whose public
signature is unchanged. First application of the decomposition recipe.

* Why: format-layer logic in the root could not be tested without linking the monolith — a filtered
  root `cargo test --lib --no-run` measured 13.45 min / 26.68 GB peak at `jobs=3`.
* #1360 build levers: L2 opt-in `[profile.dev-fast]` (cold test build 1245s → 1069s, −14%; profile
  `inherits` keeps the arrow-family `-O3` overrides); D4 advisory `rust-affected-fast` CI lane (never
  blocks a merge, skips the root); D5 deployment shapes (on-prem / cloud / no-axis / embedded) all check clean.
* Lesson: dev-fast only wins on cold/CI builds; in the sccache-warm loop the `-O0` root recompile dominates.
* Evidence: `segment_format_detect_golden_table` runs in storage-common's own suite without linking the root.
