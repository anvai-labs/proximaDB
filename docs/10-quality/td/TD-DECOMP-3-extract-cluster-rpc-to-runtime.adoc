== History

The self-contained RPC core (deps: serde/async-trait/futures/rand + `proximadb-distance-types`, zero
`crate::` climb-out) lives in the platform-tier runtime; the root re-exports it so the tonic impl and
external `cluster::rpc::*` callers resolve unchanged.

* Finding: after `rank_metrics`, the observability and catalog residue were facades cross-coupled to
  layering-forbidden tiers; `src/cluster/` is platform-legal wholesale, so it was the richest next vein.
* Remaining cluster work (tonic server + coupled modules) is tracked in link:TD-DECOMP-6-extract-cluster-consensus-to-runtime.adoc[TD-DECOMP-6].
