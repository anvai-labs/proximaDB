== Scope

Per-tenant system-catalog read accelerator (hot tier). Code comments already cite this id.

== Implementation evidence and remaining gate (2026-10-26)

`HotSysCatCache` is implemented in `crates/control/proximadb-catalog/src/syscat_cache.rs`.
`CollectionService::with_catalog_manager` constructs it in `src/services/collection/manager.rs`;
read use is gated to single-tenant/name-key cases. Existing tests cover cache integration.
Before claiming the full ADR-035 per-tenant contract, verify tenant-key isolation/admission,
version invalidation and multi-pod coherence with TD-SC-5. Reuse this implementation; do not
start a second hot cache merely because this TD was newly filed.
