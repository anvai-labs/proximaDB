== History (shipped)

`build.rs` regenerates only `proximadb.v2`. The v1 mirror (`proximadb.v1.rs`) is hand-maintained to protect its serde impls, and
nothing compared it to the `.proto`: `make proto-check` proved only that it *compiles*. Live instance: `catalog.proto` declared
`OltpCatalogConfig oltp = 17`, and the mirror's oneof stopped at 16, so binary configs decoded to `config: None`. Mechanism lesson
from the #1724 review: prost does NOT reject a removed enum value (raw `i32`) or a reserved oneof tag on binary decode (unknown
tags are skipped). Rejection of the retired Hive arm happens only at the JSON/serde boundary.

* **Guard (candidate fix 1; generate-and-diff was not needed):** `v1_conformance.rs` compiles the v1 protos with `protoc
  --include_imports` and parses all five v1 mirrors' `#[prost]` attributes, derives, enum tables and services. It compares both
  directions: names, tags, kinds, cardinality, maps, oneof tags, type references, enum wire-name maps, services and rpc streaming
  flavor. Unparseable syntax fails loud, and under `REQUIRE_PROTOC=1` (CI) a missing protoc or proto tree FAILS rather than skips.
  The ledger `v1_conformance_known_drift.json` ratchets down only (regen `UPDATE_V1_DRIFT_SNAPSHOT=1`); it must be force-added,
  because the repo `.gitignore`'s `*.json` swallowed it.
* **Burn-down 49 -> 0:** added `OltpCatalogConfig`/`oltp = 17` (the REST arm declines loudly, per TD-CAT-10), `SqlValue.jsonb_value
  = 9` with its writers switched to the declared tag (#1819 round 2: the writer had emitted tag 8, so the fix was unreachable),
  the never-mirrored PULSAR/QUASAR and embedding blocks, the `permitted_principals` attr bug (`message` over `Vec<String>`), and 7
  GraphService rpcs plus `RankService`. It deleted 6 dead mirror-only `assemble_*` messages and their `ContextService`. The guard
  caught a `Polar`/`Polaris` typo in its own PR.
* **Review program (#1836, #1843, #1845, #1852; ~50 adversarial rounds):** the canonical `SqlValue`→JSON rendering now lives in
  `proximadb_records::conversions::sql_value_to_json` (eight sites delegate; the filter lowering's int-array bytes are deliberately
  separate), and dot-path walkers delegate to `json_get_path`. Many wildcard `_ =>` arms that silently nulled JSONB were made
  exhaustive. Recurring lessons: **a guard advertising protections can be inert** (differential mutation found three dead checks);
  **a mechanical class-sweep must verify each site's searched string equals its sliced string**, or it manufactures the bug it hunts.
* **Evidence:** ledger `findings: []`; `tests/sql_value_roundtrip.rs` covers JsonbValue on both the prost and REST serde paths (mandate #8).
