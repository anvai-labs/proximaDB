== History

Extracted in #1434: `src/auth/sso/` (6 files, 4,121 LOC, 139 tests — the largest single slice of the
initiative) moved verbatim to a horizontal crate. TD-SSO-3 deleted the crate and relocated the remaining
value (`EnterpriseUserContext`) back to root `src/auth/mod.rs`.

* Lesson (still applies): moving a type out of the root can turn a root `impl From<Foreign> for Foreign`
  into an orphan-rule error (E0117); here it was replaced by a free function.
