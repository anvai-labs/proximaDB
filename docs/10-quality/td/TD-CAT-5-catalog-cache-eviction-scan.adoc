== History

Eviction at capacity no longer does a full-map `min_by_key` scan under a whole-map write lock: the maps are
sharded (`DashMap`, option 3) and the victim is chosen by bounded ring sampling (option 2, Redis-style).

Lesson that still applies: the first implementation (#1735) shared ONE eviction ring across the four map
families (namespaces/tables/indexes/statistics). `maybe_evict::<T>` pruned ring entries not resident in the
map being checked, so one family's eviction silently dropped every other family's keys; a starved family then
found zero candidates while `put_*` still inserted, growing past `max_entries` and **defeating the capacity
bound**. Fixed with per-family rings (#1772).

Evidence: `cache.rs` `eviction_rings_are_independent_per_family_under_interleaved_traffic` (fails pre-fix).
