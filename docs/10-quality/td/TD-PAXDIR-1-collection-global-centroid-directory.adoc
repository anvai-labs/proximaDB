== Problem

The coarse IVF level of the PAX cascade is per segment. A cold query pays every segment's
header, cell, rerank and row waves: 5 sequential waves and 20–80 GETs at 1M rows. Every
compaction retrains its own model, so no cell space is shared across segments.

== Plan

Slices D1–D8 are defined in the design document (§5). Slices D1–D2 work on today's segments,
with one model per segment, ranked across models by reconstruction distance. Slices D3–D6
converge on one shared model, cell-partitioned outputs, A+B co-located per cell, and decode keys
in the directory.

== Acceptance

SIFT1M on MinIO with injected latency (Toxiproxy, 50 ms RTT):

* recall@10 ≥ 0.98;
* object-cold p50 ≤ 3 sequential waves;
* object-cold p50 ≤ 20 requests per query (LIST + HEAD + GET);
* warm p50 ≤ 1 wave.

The directory-off path must not regress. BIGANN 10M is re-measured and recorded in the
evidence ledger. Exact gate definitions are in the design document, §4.2.
