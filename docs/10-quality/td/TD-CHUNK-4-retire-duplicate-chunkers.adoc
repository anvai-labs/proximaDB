== History (shipped)

* ProximaDB `crates/modalities/proximadb-embedding/src/chunker.rs` (127 lines, zero callers) and its
  `ChunkConfig`/`ChunkStrategy` mirror were deleted, and the wire `ChunkConfig` was removed with proto
  field 2 reserved by number and name (#1679, executed under TD-CHUNK-5). This also closes the
  **catalog-truthfulness item**: a persisted `Heading` policy that silently fell back to paragraph no
  longer exists. Lesson: the per-crate `cargo check` passed while the server binary was broken by the
  deletion — verify the server binary.

== The census, split by what it costs to remove

Verified by grepping for real importers, distinguishing product callers from tests. Victor's *live*
product chunking is only about **470 lines** in two paths; almost everything else is residue.

Excluded deliberately: `build/lib/` copies (7 more chunking paths) and `.claude/worktrees/` (34 more
files) are stale build/worktree artefacts, not source. And `victor/agent/services/chunk_runtime.py` is
**not a text chunker** — it streams LLM response chunks. Pure name collision; leave it alone.
