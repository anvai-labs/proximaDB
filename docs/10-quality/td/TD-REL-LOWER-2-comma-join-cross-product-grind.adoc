== History

Once #953 let comma-join TPC queries lower, 22 of them (TPC-H Q9–Q22, 8 TPC-DS) executed and then ground the raw
cross product (`lineitem × orders` at SF 0.01 ≈ 9×10⁸ pairs, ≥300 s), because the planner never normalized
`Filter(equality) over CrossJoin` into the equi-join executors Volcano already had. The failure mode *changed
shape* (fast misleading error → uncancellable grind that wedged sessions, see TD-EXEC-CANCEL-1).

Fix: textbook implicit-join normalization reusing the existing hash/nested-loop executors, applied pairwise
left-deep; native also declines a raw cross join fail-fast (`0A000`). Join *reordering* stays out of scope (TD-OLAP-2 / DataFusion).
Disjunctive shared keys and N-way connectivity followed as TD-REL-LOWER-6/7.

Evidence: planner unit `comma_join_filter_normalizes_to_hash_join_with_residual` + the native join e2es.
