== The finding

The repository carries two independently evolved Cypher grammars. The graph-query crate's
full-query grammar sat inside `parser.rs` behind a single scattered `#[allow(dead_code)]`,
reading as accidental residue rather than what the owner has declared it: **an intentional seam
to build upon** (owner decision 2026-11-01) and the convergence target for the modality crate's
drifted twin.

== Direction

1. **Seam made explicit** (landed): the write grammar lives in
   `parser/write_seam.rs` with its rationale, a single documented module-level `dead_code`
   allowance, and its 36 tests intact (47/47 green; pure code motion).
2. **Convergence design** (open): new full-Cypher parsing work belongs behind the seam. When
   the modality parser next needs a grammar change, port the clause parsers onto the seam
   (shared lexemes → shared patterns → clause-by-clause), keeping the modality's
   `CypherQuery`→`query_ast` mapping as a thin conversion over the seam's AST, until the
   modality file reduces to the conversion layer.
3. **Contract pinning** (open): before the first port, snapshot the modality parser's current
   behavior as a corpus test at the seam (the two grammars' clause-level outputs), so each
   ported clause is differential-checked against the behavior the graph API path shipped.

== Non-goals

Deleting the seam grammar (rejected — owner decision), and merging the READ path into the
modality parser (the `CompiledPattern` contract serves the SQL-lowering pipeline and stays).
