== History

Shipped before supersession: ADR-057 accepted + S1a planner + S1b ranged-rerank primitive (#827), ranged RaBitQ cascade primitives `BlockLayout` + `RangedSegmentReader::rabitq_search` parity-verified (#885), selective striped read wired default-OFF (#888), and the cost-driven whole-vs-striped chooser in observe mode (#898). The ranged-rerank substrate is consumed by ADR-062/065.
*Headline evidence that motivated ADR-062:* on the live cascade's per-query trace with the real RaBitQ candidate set, striped reads would cut cold-object bytes **72.1% (N=8k) / 73.4% (N=20k)** (5.18 MB whole-segment vs 1.38 MB striped at N=20k), versus the pure-plan bracket of 40.7–83.7% — measured trace beats plan arithmetic.
*Residual (no ticket):* `RangedSegmentReader::rabitq_search` remains in `proximadb-storage-common` with only an in-file test caller, retained dormant pending a focused removal PR.
