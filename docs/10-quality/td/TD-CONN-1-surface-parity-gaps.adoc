== The finding (sweep, 2026-07-21)

Tenant identity is *already* unified across all five surfaces via one `HeaderTrustPolicy`
(TD-TENANT-1) — the connectivity envelope is sound. The remaining gaps are per-surface *reachability*
holes for specific modalities:

[cols="1,3", options="header"]
|===
| Gap | Evidence
| **REST graph-write absent** | `network/rest/v2/graphs.rs` exposes `fusion-search` + impact-analysis only; graph edge/node writes go through gRPC `ProximaGraphService` or Arrow Flight `DoExchange`. REST is read-only for graph.
| **gRPC has no timeseries service** | Timeseries is reachable via REST v2 (`network/rest/v2/timeseries.rs`) and SQL SELECT federation, but there is no dedicated `ProximaTimeSeriesService` in `network/grpc/v2/`.
| **pgwire COPY partial; transactions = P2.D** | `handle_copy_in` vectorizes record batches but Arrow COPY is partial; `BEGIN/COMMIT/ROLLBACK` are REAL since ADR-018 P2.D delivery (2026-09-10 — buffered writes, read-only txns, 25P02 failed-txn semantics; savepoints/2PC still 0A000). COPY completion is in-scope.
|===

Cross-referenced (owned elsewhere, listed here for the completion view only): MCP checkpoint write
(TD-MCP-1), SDK spec-driven codegen parity (TD-126/TD-SDK), full ACID transactions (ADR-018 Phase 3).

== Boundary defense (what stays surface-specific — do NOT converge)

Only the *wire encoding* (HTTP/JSON, HTTP2/proto, Arrow IPC, pgwire, JSON-RPC) and the *ergonomic
facade* are per-surface. Auth, tenant trust, routing to the engine, and the request/response contract
are shared (the `HeaderTrustPolicy` + `UnifiedQueryPort`/`ComputeScheduler` core). A new surface
handler is a thin codec over that core, never a new stack — enforced by the Unified Connectivity
Envelope rule (rule seed).

== Slices (each begins with anchor re-verification)

C1 — **REST graph-write parity.** Add graph node/edge upsert + delete REST v2 endpoints that lower to
the *same* graph write path gRPC uses (reuse `ProximaGraphService` internals via the shared port; do
not re-implement graph mutation in the REST layer). OpenAPI spec regenerated in the same PR
(`make verify-openapi-spec`), SDKs regenerated (mandate #15).

C2 — **gRPC timeseries service.** Add a `ProximaTimeSeriesService` that delegates to the same TST
engine surface the REST handlers call. Proto contract + generated stubs in the same PR
(`make proto-check`).

C4 — **pgwire COPY completion.** Finish the Arrow COPY-in arm to parity with text/binary COPY, routing
to the durable single-statement DML path (M5). Transactions remain deferred (ADR-018 Phase 3).

== Sequencing

C1 → C2 → C4, all *after* M0.V2 (unified recovery) and M5 (relational durable DML) land, so every new
write surface writes through a substrate that can already recover it. No back/forward-compat burden
(nothing released) — modify in place, test the surface in isolation, move on.

== Non-goals

Full ACID transactions (ADR-018 Phase 3), SQL-over-Arrow-Flight, MCP checkpoint write (TD-MCP-1),
SDK codegen (TD-126) — each has its own home; this TD is only the parity holes without one.
