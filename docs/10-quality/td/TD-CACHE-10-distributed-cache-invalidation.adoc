== History (shipped)

The original filing premised a PubSub system (SNS/PubSub/Event Grid) to invalidate "the caches"
across pods. The 2026-08-28 co-design audit refuted it at three levels, and these findings still
apply: (1) **multi-pod is not real today** — `start_with_cluster` has zero callers, `cluster_port:
None` is hardcoded, `NodeRegistry` is an in-process HashMap, `cluster` is not a default feature — so
process-local invalidation is complete; (2) **byte-level segment caches need no invalidation, ever**
(`SegmentInvariantsCache`, `SurvivorRangeCache`, `OidResolverCache` are safe-by-immutability; DVs are
consulted after cache hits); (3) result caches are LSN/TTL-gated by contract and the per-pod-LSN
caveat is subsumed by single-writer-per-collection routing (`PrimaryPodRegistry`).

Genuine stale risks found and fixed: `VectorObjectEconomyDirectoryCache` had no TTL (pod B could
serve pod A's stale segment list until restart) → TTL re-check
`PROXIMADB_DIRECTORY_CACHE_RECHECK_MS` (default 30 s, `0` kill); the DV resident map never re-read the
shared `.dv` sidecar → re-confirm entries older than 30 s (pinned by
`sidecar_recheck_sees_cross_pod_deletes_after_ttl`). S2 bus: `CacheInvalidationEvent`
(`{schema_version, pod_id, tenant, collection, kind, lsn}`) on topic `cache-invalidation`,
`EventDedup` per-pod high-water admission (per-pod LSNs are not globally comparable), `drive_once`
poll/decode/admit/ack; default-off `PROXIMADB_CACHE_INVALIDATION_BUS=1` + queue root; publish failure
never fails the write. A Raft `Command::BumpCorpusVersion` is the natural free-rider if `cluster`
ships — recorded, not built.

Evidence: `invalidation_bus::tests` (in-process multi-pod proof incl. replay dedup).

== Multi-pod activation precondition (open)

The bus is wiring-complete, but activating it in a deployment requires
multi-pod to be REAL: `start_with_cluster` wired into server boot, peer
discovery beyond the in-memory `NodeRegistry`, and cross-pod LSN semantics
revisited (or the Raft free-rider adopted — see above). Until then the bus is
test-proven dormant scaffolding.
