== History

The checker never listed `control` as a forbidden target for the storage, horizontal or modality layers,
so 4 real upward edges passed silently (storage-common → catalog, storage-operations → catalog,
orion-engine → metrics, recall-bench → catalog dev-dep). The rules shipped at `warning` severity with a
grandfather list; link:TD-DECOMP-66-resolve-grandfathered-coupling-edges.adoc[TD-DECOMP-66] resolved 3 edges and link:TD-DECOMP-67-extract-schema-types.adoc[TD-DECOMP-67] the last, and both upgraded the rules to `error`.

* Lesson: a layering checker is only as good as its forbidden-target lists — an omitted layer is a silent pass.
