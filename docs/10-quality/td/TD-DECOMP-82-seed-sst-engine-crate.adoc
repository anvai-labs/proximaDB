== History (shipped)

The SST engine dir (~60K LOC) is the largest root block; whole-dir extraction needs an engine-port surface
that does not exist yet, so the destination crate was seeded with five leaves whose coupling had already
dissolved. It has zero root deps (ports + extracted siblings only), so later waves peel in without
re-plumbing. Root call sites coerce via new `filesystem_port()` accessors on `SstEngine` and `Compaction`;
`staged_write`'s API widened `pub(crate)` → `pub`.

* Manifest hazard (recurring): root `Cargo.toml` has a second `proximadb-engine-core` entry under
  `[dependencies]` at the file tail; deleting "the duplicate-looking" line by name breaks ~40 shims. Verify
  section headers; never delete by name-match alone.
* "Allows don't travel" again: `row_filter`'s dead `get_or_convert_vector_metadata` was deleted when the
  crate's clippy gate flagged it.
* Evidence: nextest sst-engine 15/15, storage-common 586/586.
