== History

Q19 (`(p_partkey = l_partkey AND p_brand = … ) OR (p_partkey = l_partkey AND …) OR …`) lowered fine but declined at
the planner: `flatten_and` treated the top-level `OR` as one opaque residual, so the join key repeated in every
branch was never extracted and `plan_has_raw_cross_join` declined. Fix: `(A=B ∧ p1) ∨ (A=B ∧ p2)` ≡ `A=B ∧ (p1 ∨ p2)`;
shared cross-side equalities go to the join key, the reduced disjunction stays as the residual `Filter` (absorbed
entirely when a branch was exactly `A=B`). Purely additive: a disjunction with no shared key declines as before.

Evidence: `tests/rel_crossjoin_or_factor_e2e.rs`; planner unit `comma_join_disjunction_factors_shared_equi_key`; Q19 native row-exact.
