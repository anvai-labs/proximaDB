== History

`vector_ann_recall_under_deletes_and_compaction` phase C (delete-after-flush + reflush) collapsed to mean recall 0.000 deterministically while single-flush phases stayed 1.000; an adjacent-commit bisect pinned #1406, and reverting only its two system-catalog files restored 1.000. The CI job was path-skipped on `develop`, which is why it landed invisibly.
On re-land (2026-08-15) both candidate mechanisms (collection-id floor raise; minting moving the on-disk path) were falsified, and the full reverted diff no longer reproduced the collapse on current `develop` — incidentally fixed in the DV-aware/async-compaction window. The re-land also completed relational ABAC, which had been structurally inert because `stable_namespace_id` was never minted.
*Lessons that still apply:* the root cause remains unknown — the symptom is gone, not explained — so `vector_ann_recall_e2e` is this code's explicit gate, and identity minting must not be bundled into an authorization change again (#1406 was itself an ABAC PR). A revert that removes code without diagnosing it leaves "re-land it fixed" with no defined fix. For single-test bisects use `cargo test --test <file> <name> -- --exact` (nextest `-E` hung enumerating ~195 binaries).
