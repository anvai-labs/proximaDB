== History

Two compounding defects: four IVF probe metrics (`proximadb_ivf_cells_total`, …) were declared with the
same name but different types in two modules, and the duplicate-registration fallback built a vec with
an EMPTY help string, which prometheus also rejects — so `.unwrap()` panicked a tokio worker. #1210
(coarse probe default-ON) made it reachable on every trained search. Fix: fallback reuses the real help
and returns an unregistered-but-usable vec; the aggregate operator strings become
`proximadb_ivf_cells_agg_total` etc. while the per-tenant billing vec keeps the canonical name (sum over
tenant = aggregate). Lesson: a fallback that cannot recover is not a fallback — test the error path's
own inputs. Evidence: diverse-query bed re-run no longer crashes.
