== History

MinIO's last OSS image moved from Docker Hub to Quay, and then Quay refused anonymous pulls too (verified by registry query).
The failure was deterministic, not a flake. Because `ci.yml` is in the job's path filter, any PR adding a CI step inherited it (#1957).
Options were s3mock, LocalStack, an authenticated pull, or vendoring the image; LocalStack was chosen as a full, anonymously pullable S3.
Narrowing the filter or adding `continue-on-error` was deliberately refused.

* **Licence trap:** LocalStack's date-based releases (e.g. `2026.09.1`) pull, then exit 55 with "License activation failed" unless
  `LOCALSTACK_AUTH_TOKEN` is set. `4.0.3` is the newest no-credential release, so the pin guards against *upgrade*, not just drift.
* **Readiness must be a real S3 call:** `/_localstack/health` can answer 200 while S3 still returns `NoSuchBucket` (rejected
  design; the contract test asserts against it). `diagnose()` dumps container logs and exit state, which separates "booting"
  from "exited".
* LocalStack persists `x-amz-storage-class`, so the S3 tier test became STRICT, with an out-of-band read-back that hard-fails.
* **Lesson: a `cargo test` filter that matches nothing exits 0.** A rename turns a tier arm into a silent no-op ("0 passed"), so the
  contract test now asserts that each of the gate's three positional filters names an existing test. The contract test checks
  properties (digest pin, loopback binds, readiness, filters), not a vendor regex that fails a necessary migration.
