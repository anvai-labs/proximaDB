== History

* Finding: reading was an inline `match` (no trait), and `SegmentFormat` had only `ProximaBlocks`/`Pax` — no `PAR1` arm — so Parquet was unreachable from segment dispatch, which is why the warehouse was a separate substrate.
* Shape: `PaxRecordReader`/`ParquetRecordReader` beside their formats; `ProximaBlocksRecordReader` and `record_reader_for()` in `segment_format.rs` (`ProximaDataBlock` lives above the format layer). Decoder inputs are bundled in a borrowed `SegmentReadContext` so the trait stays object-safe; the dispatch `match` has no `_` arm, so a new variant is a compile error rather than a silent legacy fall-back.
* **Decision — the `PAR1` arm is unconditional**, deviating from the plan's "behind `datafusion-integration`, default-off": `parquet` is a non-optional dependency of storage-common, and gating would retain the mis-route (Parquet bytes reaching the ProximaBlocks decoder) exactly in the least-observed build. Mandate #8 default-OFF targets coexistence hazards; this arm only changes behaviour for bytes that previously errored.
* **Lane discipline still binds (ADR-039):** the DataFusion route may use `PaxSplitReader`; the native/Volcano route must use only `PaxSegmentScanner`/`PaxScanOperator` (never `PaxSplitReader`, which would break the no-DataFusion build guard, TD-DFSEAM-1). The ~30 lines of decode duplication are deliberate (TD-OLAP-14) — do not share the reader across lanes.
* Status note: TD-OLAP-1's claim that TD-162a-3 was "satisfied by the existing reader" was loose — the reader met TD-OLAP-1's needs but did not introduce the trait.
* Out of scope (ADR-094 Phase 3 landing-format work): registering Parquet at `read_segment_records` call sites (cold-search, compaction, recovery) — no writer emits Parquet into a vector segment path.
* Evidence: `segment_format_detect_precedence_all_four_magics` (incl. adversarial hybrids), `trait_dispatch_is_byte_identical_for_existing_formats` (whole-record equality), `parquet_segment_routes_to_the_parquet_reader` (non-vacuous), `parquet_reader_errors_on_corrupt_input`, `cargo check -p proximadb --tests --no-default-features`.
