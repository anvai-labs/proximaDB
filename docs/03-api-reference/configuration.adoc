= Configuration Reference
:toc: left
:toclevels: 2
:icons: font

[.lead]
Configuration reference for developers running ProximaDB locally or in a single‑node environment.

== Minimal Config

[source,toml]
----
[server]
bind_address = "127.0.0.1"
port = 5678
data_dir = "/var/lib/proximadb"
log_level = "info"

[api]
grpc_port = 5679

[storage]
default_engine = "sst"
----

== Server

[source,toml]
----
[server]
bind_address = "127.0.0.1"
port = 5678
log_level = "info"
data_dir = "/var/lib/proximadb"
----

`data_dir` is used for WAL and model data (vectors, documents, observability).

== API

[source,toml]
----
[api]
unified_mode = true          # 5678 multiplexes REST + gRPC + Arrow Flight
                             # (Arrow Flight is Experimental per
                             # SUPPORTED_SURFACE; set in the shipped
                             # config.toml / docker image; the
                             # CODE default is false — k8s/helm artifacts run
                             # legacy multi-port unless they set it)
rest_port = 5678
grpc_port = 5679             # legacy multi-port mode only (unified_mode = false)
arrow_flight_port = 5680     # legacy multi-port mode only
max_request_size = 67108864
rate_limit = 1000
----

== Storage (Vectors)

[source,toml]
----
[storage]
default_engine = "sst"
metadata_url = "file:///var/lib/proximadb/metadata"

[[storage.storage_locations]]
url = "file:///var/lib/proximadb/data"
weight = 1

# Optional per-location I/O budget (TD-IOBUDGET-1): sizes ranged GETs for
# THIS location. disk_class: "ssd" | "hdd" | "cloud"; explicit
# min_bytes/target_bytes/max_bytes override the class profile (validated,
# fail-closed at startup). Unset => URL-scheme default.

----

== WAL

WAL backs vector, document, and observability writes.

[source,toml]
----
[storage.wal_config]
enable_wal = true
global_manifest_url = "file:///var/lib/proximadb/manifest"
memory_flush_size_bytes = 16777216
sync_mode = "async"
----

== Graph

[source,toml]
----
[graph]
default_engine = "orion"
wal_enabled = true
----

== Security (Optional)

[source,toml]
----
[security]
auth_enabled = false
token_secret = "change-me"
----

== Notes For Builders

* Use `sst` for general‑purpose vector workloads.
* Document and observability WAL files live under `data_dir`.
* Observability storage is partitioned and currently in‑memory.
