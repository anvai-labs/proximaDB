**Date:** 2026-10-27 · **Branch:** `bench/tier1-e1-fixed` — runs executed at worktree HEAD `248f214f2` with the **binary sha256 `11b6a8a1…` (built from the `f5aef1b0b` tree 2026-10-26 13:20, never rebuilt)**; result.json `binary.source_revision` records the run-time HEAD, not the build commit — see Provenance for the tree-range and rebase caveats · **TD:** link:../../10-quality/td/TD-TIER-1-collection-storage-policy-and-residency.adoc[TD-TIER-1] SC0/E1 · **Companion to** link:TIER1_E1_FIXED_OBJECT_CAP_SWEEP_2026_10_26.adoc[the 1M E1 run].

== Protocol

Same fixed-object protocol as the 1M run, per scale: one bed built once, ETag-fingerprinted, then cap arms (4/16/40 MiB) via `--skip-ingest` reuse — identical objects, model and query IDs; only the cap varies. Corpus: the first 3M/10M vectors of the ANN_SIFT1B **learn split** (the official base split is FTP-only and this host's FTP data channel is blocked; the learn split is the same 128-d u8 SIFT descriptor distribution — disclosed, not hidden). Ground truth: exact top-100 computed per-prefix against the same corpus (4096 queries covering all three phase windows), satisfying the harness's subset-GT contract (`--groundtruth-scope-rows`). **n=1 per arm at scale** (exploratory; the 1M run established repeat behavior) — labeled accordingly.

== Findings

. **Single-segment scale: the cap effect strengthens.** At 3M (one segment), 4 → 16 MiB cuts requests **−35%** (36.342 → 23.634) — larger than 1M's −28.67% — and removes a wave (5 → 4). 16 → 40 saves only 0.56 req/q at the same p50 with p99 +27 ms. Same shape as 1M, stronger effect. [M]
. **Multi-segment scale: the cap saturates.** At 10M over 3 segments, 4 → 16 MiB cuts only **−5.5%** (81.419 → 76.907) with no wave change; 40 MiB adds nothing. Under segment fan-out each segment issues its own probe ranges — a per-segment request floor the coalescing cap cannot merge across. **Segment count, not the cap, becomes the dominant request term** at multi-segment scale. [M]
. **The 3-segment bed is not a protocol accident — it is what compaction produces.** A follow-up run requiring exactly one segment (`--max-segments 1`, 3600 s settle) timed out with the bed stable at 3 segments and zero unready segments — the harness error verbatim: `materialization/compaction did not quiesce: rows=not-snapshotted/10000000, segments=3 (max 1), last_parse_error=None, unready_segments=[]` — the tier-merge policy does not emit a single 2.5 GB segment for a 10M corpus under current triggers. The 10M row above is therefore the *shipped shape's* measured behavior, not a confounded approximation. A single-segment 10M fixture would require compaction-trigger work (its own slice); recorded as the blocker. [M]
. **Geometric nprobe under-covers at scale (product-gate item, not an experiment defect):** cells probed 15/56 (27% of cells, 26% of rows) at 3M → recall 0.9740; 43/454 (9.5% of cells, 9.3% of rows) at 10M → recall 0.9715 — both below the 0.98 SIFT1M product gate. Recall is **constant across caps within each scale** (identical probe plans), so the cap conclusions are unaffected. nprobe calibration for product gates at scale is the design's anticipated follow-up (the D7-sweep-calibration item); the arms here deliberately used default nprobe to hold the protocol comparable to the 1M run. [M]
. **First scale measurements of the full p99/RSS/CPU telemetry** — landed with these runs, no server code change needed. [M]

== What this does NOT establish

n=1 per cap per scale (no repeats) — directions, not distributions. The corpus is the learn split, not the base split. Cross-scale comparison is confounded by bed shape (the 10M single-segment counterfactual was not producible). Fragmented segments, filtered queries and 768d remain unmeasured. **No default change and no pricing claim rides on this run** (production S3 already targets 8 MiB ranges; the design's stop rule still requires the fragmented/filter finalists before any global flip). The 10M finding sharpens the deferred-D4 question — segment fan-out is now a measured, not assumed, request term — but D4 stays deferred until its measured-need gate is met.
