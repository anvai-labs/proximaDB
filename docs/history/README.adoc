  UDTF routing is not universal ABAC or PAX admission.

  Warm discovery, broad scale proof and deferred physical co-location remain separate.
* SC0 design/harness and the #2249 cap pilot landed. Different cell geometry prevents a causal

The archived execution tracker carries PR-level details and the reconciliation audit carries
branch/cleanup evidence. Past statements must be interpreted at their source commit/date.
