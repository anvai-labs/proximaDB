= Release roadmap
:toc:
:last-updated: 2026-10-26

Release ordering and exit criteria live here. link:TRACKER.adoc[Tracker] owns delivery status
and session ownership; the plans own implementation contracts. TDs retain issue-level detail.
A release gate can remain open after its enabling code lands; the tables below are acceptance
work, not a second list of every completed PR. Confirm remaining TD slices before pickup.
link:../SUPPORTED_SURFACE.adoc[Support contract] alone decides supported claims.

== Close a release

Require executable exit checks, no weakened conformance/recall ratchet, crash and protocol
proof on affected paths, fresh diff review, and ADR-096 consistency across direction,
requirements, support and diagrams. Explicitly move deferred gates here with a reason.
Packaging code alone does not prove the published release image. SF1 load/publication memory
proof is not SF1 query correctness or SF10 readiness.

== Immediate milestone and dependencies

with pushed predicates and a coherent read token while publication/compaction race the query.

== Later (ordered, after v1.0)

. **Scale out**: distributed transport and failover verification (TD-077), then replication and
  multi-node failure-injection validation, then elastic compute modes (TD-089).
. **Agent memory**: write surface, framework adapters, branching, and the neutral fusion core
  (TD-101, TD-102, TD-117, TD-136, TD-137).
. **Time-series, events and observability** graduate as projections of the canonical record
  (TD-063); time travel by LSN (TD-116).
. **Lineage** hooks for vector, document and graph writes, beyond MLOps (TD-MLOPS-1).
. **Broader interoperability**: Spark/Trino certification beyond the immediate v3 read-back gate (TD-119), Lance (TD-091),
  Spark and Hadoop connectors (TD-097, TD-099), external collections residual (TD-090).
. **In-database inference** and **billion-scale vector indexes** (DiskANN, after TD-064).
