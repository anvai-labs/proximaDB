== 1. Positioning this document executes

ProximaDB is the **lakehouse system of record for AI context**. Every modality lands as an open
table on object storage under one catalog, one record identity and one snapshot. Analytics is
the proof, not the product: TPC-DS and the multimodal benchmark show the claim holds; they are
not a warehouse race. This sharpens ADR-096 D1 ("SQL-first context engine on object storage");
it does not change it.

== 2. Where the vision is ahead of the code

The 2026-10-18 survey below is historical motivation, not current status. Consult the
execution tracker before implementing a gap; many prerequisites have landed. The active
publication direction is v3-first (owner reaffirmed 2026-10-26, ADR-097 D3).

. **Two disjoint Iceberg metadata trees.**
** The REST tree has dangling manifest URLs, a synthetic schema, a `commit_table` stub, and is
   hard-coded to format v2.
** The MATERIALIZE tree is v3-labelled but lacks parent snapshot ids and row lineage, writes
   relative paths, and has no Avro header metadata.
** No test reads a table back with an external reader.
. **The write path is not a lakehouse write path.**
** The canonical WAL is one local file with an O(WAL) decode, no rotation and no truncation.
** Layer A (`SpillRecordStorage`) has no production caller.
** MATERIALIZE buffers the whole table (3–4 copies) into one `part-0.parquet` and drops `oid`
   and the system columns.
. **SQL depends on format because of a registration gap, not a storage limit.**
** Only `ObjectStoreParquetTable` is registered with DataFusion.
** The native path is a `MemTable` capped at 1M rows.
** `PaxTableProvider` has no production caller.
** Cross-modal UDTFs are eager `MemTable`s with literal-only arguments and string ids (no
   `oid`), and push down neither filters nor limits.
. **Modalities are not canonical-WAL-authoritative.**
** Observability has its own WAL and no tiering at all; `tier_down` has no caller.
** Graph mirrors into a cold store via `upsert_record`, not a WAL `RecordUpsert`.
** `oid` is namespaced per modality, so there is no shared identity.
. **The vector tiers are split.**
** The default PAX cascade is turbopuffer-shaped but costs 20–80 GET/query cold, against
   turbopuffer's 3–4 round trips.
** AXIS HNSW is memory-only and rebuilt on cold start.
** AXIS IVF on disk/cloud is a placeholder
   (`src/index/axis/storage/ivf_posting_list_storage.rs:339`).
** A vector collection created without an index defaults to HELIX, which measured 2% recall
   (link:../10-quality/td/TD-ENGSEL-1-auto-selected-engine-is-beta-helix.adoc[TD-ENGSEL-1],
   link:../10-quality/td/TD-HELIX-3-multi-engine-benchmark-low-recall-helix-swift.adoc[TD-HELIX-3]).

== 3. Part A — Thought experiments (each one decides a seam)

[cols="1,3,5,5", options="header"]
|===
| # | Experiment | What breaks today (evidence) | Decision it forces

| TE-1
| **Analyst's join:** "tickets semantically like X, from customers who churned last quarter,
with their agent-session error logs, grouped by plan"
| `vector_search` runs eagerly into a `MemTable`. Its arguments are literals only, its filter
is post-hoc, and it returns a string `id` (`src/datafusion/cross_modal.rs:150-267`). A
UDTF-only query never reaches DataFusion (empty `tables` map). Logs are not in SQL.
| **S5/S6:** modalities are lazy `ExecutionPlan`s under one logical IR, with filter, limit and
dynamic-filter pushdown, and they return `oid`.

| TE-2
| **Spark/Trino/DuckDB reads our table** through `/iceberg/v1`
| REST serves `_manifests` (empty for MATERIALIZE tables). Manifest-list URLs 404, the schema
includes columns the files don't have, and `file_path` values are not URIs.
| **S4:** one Iceberg writer is authoritative, REST serves its `metadata.json` verbatim, and
CI reads tables back with an external reader.

| TE-3
| **Firehose:** OTLP logs/metrics at 50k rows/s, query freshness ≤ 2 s, 30-day retention
| The canonical WAL is a single file and `read_changes_since` decodes all of it.
Observability has its own WAL and no tiering. Layer A has no time partitioning.
| **S2/S3:** segmented WAL with a per-collection index and truncation; time-partitioned
Layer A for append-only modalities; retention = `RecordPartitionDrop` + snapshot expiry.

| TE-4
| **Forget a user (GDPR)** across rows, vectors, graph edges, documents and logs, including
published snapshots
| `oid` namespaces differ per modality. MATERIALIZE sets `oid` to the row index
(`src/services/dml/mod.rs:2317`). Iceberg has no deletes. HNSW delete is O(E).
| **S1:** one identity scheme plus an entity/subject key system column. **S4:** v3 deletion vectors directly; legacy v2 reads and atomic upgrade only.

| TE-5
| **Cold start at 100M × 768d**
| HNSW at ~620 B/vector plus fp32 vectors is about 370 GB of RAM, with a full rebuild on
restart. AXIS IVF disk is a placeholder. The PAX cascade at 10M already costs 52.9 GET/query
and p50 417 ms
(link:../_internal/status/BIGANN_NPROBE_GEOMETRY_COMPLETE_2026_08_06.adoc[BIGANN_NPROBE_GEOMETRY_COMPLETE]:67-75).
| **S7:** the object-store centroid tier is the scale answer. HNSW is an optional hot
projection rebuilt from it, never the authority.

| TE-6
| **Graph + aggregate:** "average citations per year of papers ≤ 2 hops from X that are
semantically near Y"
| `graph_traverse` runs one Cypher query per depth into a `MemTable`, returns a string
`node_id`, and its pgwire reachability is unverified
(link:../10-quality/td/TD-XMODAL-10-graph-traverse-udtf-pgwire-reachability-unverified.adoc[TD-XMODAL-10]).
ORION is not WAL-authoritative.
| **S3/S7:** edges are a Layer A table sorted `(src, label, dst)`, with ORION CSR as a
rebuildable index. Traversal ≤ 3 hops = recursive join; deeper = `GraphExpandExec` over CSR.

| TE-7
| **Documents with drifting nested JSON**, faceted aggregate
| A document read fetches the whole 329 KB segment (`range_gets=0`, ADR-055). Parquet export
fails closed on type drift (USCHEMA review).
| **S3:** shredded typed columns plus a variant/JSON residual column. Publish as Iceberg v3
`variant` when external readers support it, JSON string until then.

| TE-8
| **Write at t, SQL at t+1 s** on a 50M-row table
| The WAL-delta merge is `MemTable`-based (`register_merged_olap_table`,
`src/query/execution/datafusion_engine.rs:925`) and does not stream.
| **S5:** a streaming union of the published snapshot and the WAL tail (the same pattern
turbopuffer uses for its unindexed WAL tail).

| TE-9
| **Double the data:** TPC-DS SF 0.05
| MATERIALIZE runs out of memory (whole-table batch): OOM-killed at 13.7 GB RSS on a 15 GB host
(link:../_internal/status/TPC_DS_SPEC_PRUNING_EVIDENCE_2026_10_18.adoc[TPC_DS_SPEC_PRUNING_EVIDENCE]:32-33).
The same figure was also quoted for an unrelated rustc OOM in TD-OLAPFMT-2; that attribution
is corrected (§7) and the peak should be re-measured.
| **S3/S4:** streaming, multi-part, bounded-memory publication.

=== Resolving the S6 vs ADR-054 conflict

Fused operators stay in native crates, which keeps ADR-039's no-leakage rule. They plug in as
DataFusion `ExecutionPlan` adapters living in `src/datafusion/`. The logical IR is DataFusion;
the physical operators can be native. This supersedes TD-OLAP-13's premise ("DataFusion
structurally cannot host a fused ANN+filter+aggregate"), not its operators: DataFusion's
`TableProvider::supports_filters_pushdown`, `limit` and dynamic-filter pushdown carry the
predicate *into* the search, which is the property TD-OLAP-13 needed. See ADR-097 D1.

=== Verdict

* The PAX cascade is the right architecture. It is the only tier aligned with the lakehouse
  seams (S2–S4, S7).
* Its gap to turbopuffer is **round-trip depth, not recall**. Today's per-segment cells mean
  one query touches many segments, each with its own A0 → A → B ranged reads.
* HNSW stays a *hot projection* for small, latency-critical namespaces, built from PAX and
  dropped without data loss.
* AXIS IVF folds into PAX as a **collection-level centroid directory** rather than growing its
  own disk posting lists. The AXIS IVF disk/cloud posting-list path is retired (ADR-097 D2).

=== Closing the depth gap

Target: cold ≤ 3 sequential waves and ≤ 20 GET/query at 1M; warm 0–1 wave.
The design, gates and PR slices are in link:P5B_PAX_CENTROID_DIRECTORY_DESIGN.adoc[P5B_PAX_CENTROID_DIRECTORY_DESIGN] (TD-PAXDIR-1).

. **Collection-global centroid directory (wave 0, cached).** Compaction emits a small
  `centroids.pax` per collection snapshot, published as an S7 projection. Queries pick nprobe
  clusters globally instead of probing every segment's A0.
. **Cluster-contiguous compaction.** Compaction rewrites segments so each cluster's region A+B
  bytes sit together. nprobe clusters then cost about nprobe coalesced ranged GETs issued in
  **one parallel wave**. This reuses `block_cluster.rs` (k-means/PCA) and the existing
  coalescer.
. **Co-locate SQ8 (B) next to RaBitQ (A) per cluster.** Rerank then needs no extra wave; only
  top-k row rehydration (D) remains as a second wave.
. **Local-disk L2 cache on by default** when a scratch volume exists (ADR-085
  `PersistentByteStore`). Turn cache-affinity routing on (VOE Phase 7); its registries already
  exist.
. **Unindexed WAL tail = exact scan,** merged with ANN results (same as TE-8).
