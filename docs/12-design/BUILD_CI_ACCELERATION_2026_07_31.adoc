*Goal:* faster + more memory-predictable compile / link / CI, with **zero** API,
wire, on-disk-format, feature-default, or recall changes.

== History (shipped)

* *D1 baseline (2026-07-31):* the root `proximadb` crate is an 850K-LOC monolith
  (`src/storage` 325K); one filtered root-lib test = **13.45 min wall, 26.68 GB peak RSS
  @ jobs=3** — the reason CI pins `CARGO_BUILD_JOBS=1`. Leaf-crate tests compile in seconds.
* *L1 (#1344):* `SegmentFormat`/`detect`/`is_pax_segment` + PAX-decode moved root →
  `proximadb-storage-common` (root keeps a re-export; signature unchanged). Unit-testable in the leaf.
* *L2 (#1360):* opt-in `[profile.dev-fast]` (deps at `-O1`; arrow/parquet pins stay `-O3`);
  `cargo check --profile dev-fast`. Not shared with `test` artifacts — toggling recompiles.
* *D5 (#1360):* deployment shapes (embedded / on-prem full / cloud / exact-scan-only no-axis)
  are additive feature bundles validated by `cargo check`; no cfg-divergent forks.
* *D4 (#1360, fixed #1511):* advisory `rust-affected-fast` lane runs `nextest --lib` on touched crates.
  **Lesson:** skipping the root crate *by name* was not enough — `-p <crate>` compiles its whole
  dependency graph, and 9 members (root, `crates/binding/*`, `apps/*`, `proximadb-sdk`) pull the
  monolith back in; 8 of 80 runs died at the 915s timeout wall, and `rust-cache` (saves only on success;
  `develop` pushes diff empty) could never amortize it. Fix: `affected_crates.py
  --exclude-dependents-of proximadb` (115/124 crates eligible), timeout 15m→10m; guarded by
  `tests/scripts/test_affected_crates.py`.
