== History

fp16 records now survive the whole SST path: the Arrow bridge emits/decodes `Float16Array`,
SST/HELIX/SWIFT writers consult the per-collection canonical precision (`CanonicalPrecisionResolver`,
shared with the drainer's `target_precision` channel), and compaction re-applies the precision via
`CompactionTask.precision_hint` + `EmbeddingCell::coerce_to_precision`.

* **Finding:** "flip the writer to PAX v2" was not a one-shot wire-up — the SST file format was
  **Arrow IPC end-to-end** (the `PROXSST\0` magic is the *file* header; blocks were `RecordBatch`es,
  not `PXBL` blocks), and the bridge narrowed fp16 to fp32 before any writer saw it. Bridge-first was
  chosen over a PAX-native engine rewrite.
* **Lesson:** compaction silently dropped precision through the legacy `VectorRecord` hop
  (`proxima_record_to_vector` → `Vec<f32>`); fixing the bridge was necessary but not sufficient.
* `encode_pax_v2_block` / `PaxBlockHeaderV2` / `should_use_v2_for_records` remain as primitives for a
  future PAX-native path; they are not on the live flush path.
* **Pins:** `sst::compaction_tests::fp16_records_survive_compaction_round_trip_bit_exact` (un-ignored),
  `arrow_block::writer::tests::fp16_file_is_approximately_half_the_fp32_size`.
