= Graph Runtime
:toc: left
:toclevels: 3
:icons: font
:source-highlighter: rouge
:last-updated: June 2026

[.lead]
ProximaDB now has one graph runtime: ORION. Distributed placement, execution
coordination, and projection tiering are not separate graph engines; they are
provided by the relational distributed substrate, xCatalog policy, and storage
runtime.

== Current Runtime

[cols="1,2,2,1", options="header"]
|===
| Runtime | Role | Scale Path | Status

| ORION
| Graph projection runtime for node/edge traversal, graph RAG, and relationship queries
| Relational partitioning/routing, cataloged projection policy, and storage tiering below ORION
| Active
|===

ORION consumes canonical graph facts lowered through the shared record/catalog
spine. CSR and adjacency structures are rebuildable topology projections, not a
separate durable authority.

== Layering

[source,text]
----
Graph API / traversal / graph RAG
        |
      ORION
        |
Graph projection + graph-specific planning hints
        |
Relational distributed planner/coordinator
        |
xCatalog partitioning, routing, placement, WAL, policy
        |
Storage layouts, object store, open formats, compute backends
----

== Retired Engine Names

PULSAR and QUASAR are retired as graph engine variants.

* Former PULSAR concepts such as placement, fanout/fanin, and shard-aware
  traversal are requirements for the relational distributed planner.
* Former QUASAR concepts such as access tracking and hot/cold movement are
  requirements for xCatalog/storage projection policy.
* Requests that specify `pulsar` or `quasar` are rejected; use `orion`.

== Example

[source,python]
----
from proximadb_sdk import ProximaDBClient, Protocol

client = ProximaDBClient(url="http://localhost:5678", protocol=Protocol.REST)

# create_graph takes no engine argument.
client.create_graph("recommendations", name="Recommendations")
----

== Guidance

Use ORION for all graph workloads. For scale-out and cost optimization, configure
the relational/catalog/storage layer rather than selecting another graph engine.
