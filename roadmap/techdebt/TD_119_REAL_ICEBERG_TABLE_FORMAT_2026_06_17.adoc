== Managed publication

The original June key-list migration delivered versioned metadata, Avro manifests and manifest
lists. Managed publication now goes through the Iceberg engine. TD-SEAM-1 owns production
writer/REST discovery and schema fidelity. TD-SPINE-3 and TD-SPINE-4 own metadata retention
and scan planning. TD-117 retains its dependency on usable snapshot refs for branching.
link:../../docs/12-design/adr/ADR-097-foundational-seams-single-logical-ir.adoc[ADR-097 D3],
link:../../docs/current/LAKEHOUSE_PLAN.adoc[publication and read-back contract]

Qualify each managed publication using the production SQL and REST catalog paths.
Compare pgwire values with pinned external readers across two snapshots, including deletes
and a tenant-negative case. Record the producer, reader, table format version, enabled
features and snapshot IDs. Existing PyIceberg/DuckDB tests supply the starting fixtures.

== External read qualification

In the reverse direction, read a producer-published UniForm projection through pgwire.
Compare typed rows with an independent Delta reader at the represented source version.
Exercise both Iceberg v2 and v3 projections, including a nonempty deletion vector on v3.
Reject an inadequate freshness guarantee or unsupported feature. A plain Delta log goes
through the separate Delta read track. RFC-0003 owns the source matrix and fixture details.
link:../../docs/rfcs/0003-open-table-analytics.adoc#iceberg-delta-compatibility[protocol evidence and fixtures]

The Iceberg storage planner accepts a producer-supplied immutable metadata URI and
an independently authorized table root. A UniForm caller supplies the expected
`converted_delta_version`. The planner requires an exact match before opening the
manifest list and resolves the referenced objects within the authorized prefix.
The storage regression uses a locally generated producer-style metadata filename,
advances the managed tip, and verifies that the older pinned snapshot and its
deletion vector still resolve.

The pinned DataFusion provider projects each Parquet file by its physical Iceberg
field IDs, returns the current schema's names and order, and applies v3 deletion vectors
before emitting rows. This covers flat schemas with field-ID-bearing Parquet, including
renamed or reordered fields and optional additions without a stored default or identity
partition value. Nested projection, name mapping for ID-less files, and synthesizing
non-null defaults or missing identity partition values remain outside this slice.

For the pgwire read slice, register the producer's table root and its immutable
metadata URI separately. Supply the exact converted version when reading a UniForm
projection. The SQL columns must match the supported snapshot schema in name, type
and order.

[source,sql]
----
CREATE TABLE sales_snapshot (id BIGINT, amount DECIMAL(12,2))
WITH (
  format = 'iceberg',
  authority = 'external',
  external_location = 's3://warehouse/sales',
  iceberg_metadata_location = 's3://warehouse/sales/metadata/00007-producer.metadata.json',
  converted_delta_version = '42'
);
SELECT id, amount FROM sales_snapshot ORDER BY id;
----

The operator's `PROXIMADB_EXTERNAL_TABLE_ROOTS` allowlist must cover the table root.
The read route checks the allowlist again on open. Unix local reads open files
relative to the configured directory and refuse symlinks beneath it. S3 and GCS
use their object-store backends when present in the build. Registered pinned
tables are read-only. The first pgwire slice handles unqualified names in the
default namespace and reads pinned Iceberg tables under an ungoverned identity.
Mixed-storage queries, policy-governed scans and EXPLAIN are deferred.
pgwire renders exact decimal values as text with its current wire type mapping.

Qualify the catalog-backed path with independently produced UniForm fixtures.

Attach a result per tested producer/reader/feature combination. Wider Spark/Trino
certification follows the release roadmap. TD-OLAP-4 owns comparative timings after
value parity. link:../../docs/current/ROADMAP.adoc[release sequence]
